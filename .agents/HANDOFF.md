## 二、未开始的下一步工作（下一步）

接手者或后续开发进入下一阶段时，请按照以下优先级与路线推进：

### 🎯 任务一：平台 V5.0 第 1 阶段实施 —— 后端轻量中枢与统一 API 解耦
- **工作目标**：构建 `project/src/platform_core/v5/` 单一扁平服务，摆脱旧版深层类继承与动态 HTML 劫持。
- **推荐步骤**：
  1. 实现 `hub.py` 控制器中枢，将航拍 M0、Frontier、地面 192 题库及云端 API 统一封装；
  2. 实现 `v5_server.py`，提供标准 RESTful API（会话创建、单步执行、自动推演、状态/图像获取）；
  3. 在独立测试端口（如 8798）上跑通端到端功能验证，确保老平台 8769 稳定运行不受影响。

### 🎯 任务二：平台 V5.0 第 2 阶段实施 —— 前端一体化单页框架（SPA Shell）与设计系统
- **工作目标**：落地统一学术科技风 Design System，打造单页工作台中枢。
- **推荐步骤**：
  1. 编写统一主题变量库 `v5_theme.css`（支持深空石墨灰与学术纸感白无缝切换）；
  2. 实现通用 Canvas 2D 视网膜级网格地图引擎与通用双视窗图像对比器，消除重复代码；
  3. 构建左侧 Mode Rail 与底部统一时间轴推演控制器，实现模式秒级无刷新平滑切换。

### 🎯 任务三：平台 V5.0 3 分钟极速演示向导（Wizard）开发与上线
- **工作目标**：彻底解决新手引导差的问题，为导师和评审专家提供零门槛的一键演示流。
- **推荐步骤**：内置 3 套经典演示预设（航拍 10 步精准入洞、地面拍摄点人机协同、本地 M0 vs 云端大模型打擂），设计气泡式引导高亮卡片。
