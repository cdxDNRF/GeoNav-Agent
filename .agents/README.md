# 开发协作入口

| 入口 | 用途 |
|---|---|
| [TASKS](TASKS.md) | 当前任务、执行者、写入范围及剩余事项 |
| [HANDOFF](HANDOFF.md) | 最新交接簿：只记录刚完成的上一步与未开始的下一步（严禁流水账，历史阶段归档至`归档/.agents/`，常驻保持≤150行） |
| [PROJECT_STATE](../docs/PROJECT_STATE.md) | 当前研究及平台事实 |
| [AGENTS](../AGENTS.md) | 长期规则 |

一次性接手提示、外部开发工具说明、配置和回执统一放`本地/`，不上传GitHub。这些是本机运行记录，不是导航算法功能。历史拆分备份仍在`归档/`。

本机层级：`本地/接手提示/`、`本地/工具说明/`、`本地/工具说明/原件/`、`本地/工具记录/`。历史外部助手源码在`project/src/tools/local/archive/`，有旧路径假设，不直接当当前命令执行。2026-10-05迁移清单在`本地/整理记录_20261005_v1/核验/文件迁移映射_v1.json`；原件SHA保持不变。

仓库公开范围与本地恢复依赖见[Git收录说明](../docs/维护/Git收录与本地数据说明.md)。

### HANDOFF.md 维护铁律（防流水账规则）
- **核心定位**：专为下一个接手人/Agent 准备的单帧即时交接文件，**只记录刚完成的上一步（已完成成果）与未开始的下一步（待办清单）**。
- **严禁流水账**：严禁把 HANDOFF 当成无限追加的操作日志或逐轮对话记录；禁止粘贴大段终端输出或代码碎片。
- **行数红线与归档**：正文建议控制在 100~150 行（绝对上限 200 行）。一旦阶段结束或接近上限，必须按镜像路径归档至 `<项目根目录>/归档/.agents/HANDOFF_历史累积归档_YYYYMMDD.md`，主文件更新为纯粹的单帧当前状态。
- **后台进程状态**：移交前必须确保零僵尸后台进程，释放所有调试/服务端口。
- **完整规则**：详见 [AGENTS.md](../AGENTS.md) 第 8 条规则。
