# 主动探索平台 V0.1

这是**已保存轨迹回放平台**。目标是让课程报告和答辩能解释实际实验：给定目标图、逐步获取航拍观察、探索器提议、目标线索介入、覆盖/径向保护与终局结果。没有实时导航按钮，不产生新SR。

在仓库根的PowerShell执行：

```powershell
& 'D:\PYTHON\python.exe' -B -m project.src.webapp.server_v1 --port 8766
```

等待“平台地址”后，打开[本机平台](http://127.0.0.1:8766)。服务仅监听127.0.0.1，终端Ctrl+C停止。启动约需数秒校验；无GPU、云端或新增npm依赖。如果端口被占用，使用`--port 8767`并打开对应地址；不要停止不明进程。

也可以右键本目录[启动平台.ps1](启动平台.ps1)，选择用PowerShell运行。启动器会先尝试已启动的同版服务；没有匹配服务才启动，并打开浏览器。终端保持运行，关闭即停止服务。脚本未签名时直接使用上方命令，无需修改系统执行策略。

## 演示操作

1. 在左侧选择数据协议、策略、权重、区域和任务。成功/失败可筛选，默认完整队列。
2. 播放、逐步前进/后退或点击进度条。当前位置的决策面板表示将要执行的动作；终局显示到达/预算耗尽。
3. 当前步只展示已经观察的图块和已执行路径。目标图单独展示，默认不标真实目标格；勾选“事后真值叠加”仅用于解释失败。
4. 实验总览是完整计划队列的三权重汇总，不受左侧筛选影响。SG含全部终局，成功为0，单位米；移动距离独立报告。
5. 展开原件路径/SHA或导出本条JSON查看原始决策、任务和来源。导出含事后任务真值，标为诊断材料，不能作为策略输入。

## 边界与下一步

当前是训练过的单导航Agent、同模态航拍目标与网格定位的实验回放。没有地面照片检索、全球经纬度搜索、任意角度/异时适配或实飞功能。**V0.2才接界面驱动的真实模型推理与环境步进**，先使用已消费开发区域和冻结策略；新增日志写新批次，历史原件、默认和3备用区保留。
