# GeoNav实时导航平台 V2

在仓库根运行：

```powershell
& 'D:\PYTHON\python.exe' -B -m project.src.webapp.server_v3 --port 8767
```

打开 http://127.0.0.1:8767 。历史回放V1仍使用8766；两者独立，原v1源码和封存记录保持。

也可以右键本目录[启动平台.ps1](启动平台.ps1)，选择用PowerShell运行。启动器先探测8767上已就绪的同版实时服务（`/api/meta`身份匹配），匹配则直接打开浏览器；否则从仓库根启动`server_v3`，待输入/源码绑定校验完成、服务就绪后自动打开浏览器。终端保持运行，关闭或Ctrl+C即停止服务。脚本未签名时直接使用上方命令，无需修改系统执行策略。

## 实际功能

- 已消费开发区100任务：25题5×5/B10、75题10×10/B20；选任务、M0/Coverage3Radial（10格）/Cloud、seed0/1/2后开始新会话。
- 单步/自动、暂停自动与结束本次运行，展示目标/当前图、已观察网格和执行轨迹，终止后导出JSON。
- 冻结图像编码缓存供环境查找两图特征，GRU/目标视觉头每步真实forward；这是真实策略导航，不是轨迹重放，也不是每步重新运行Sat2Cap。
- 同题批量：每臂前1–20题固定队列，M0/Cloud或10格M0/Coverage对照；按计划分母计算SR，队列未完成时完整SG为null。
- API：兼容chat/completions，支持HTTPS或本机HTTP、可选Key、30秒超时/512输出tokens默认。现有Gemma配置可自动从本地project/.env读取；不初始化发送请求。Key只后端内存，不回显/写入运行文件。地址/模型改变且Key留空不会复用旧Key。
- 方法页复用绘图/平台方法图_v1的SVG版本，涵盖训练/在线闭环、决策公式参数、20题工程结果。

## 日志与限制

每次运行另建DATA/processed_data/MassGIS/平台运行/live或batch_UUID，保存首动作绑定、动作、终局/seal。此目录只本地保留；公开选择性对照证据在平台单模型对照_v1批次。不要覆盖或以新运行冒充未见数据。

当前任务只来自img_6100一个已消费开发区域，15格和3备用区不开放。Cloud只接收两图和公开Observation，不传目标坐标/距离/源身份/全图/未访问图块。原始评分由环境终局计算，成功距离0，基础四动作/越界耗步及最后一步成功规则保持。

Cloud输出失败时明确使用本地M0回退；3次连续错误后停止，不自动重试。单会话最多20请求、批量最多400请求；调用、失败/回退、tokens和时延另报。含回退结果不是纯云模型SR。单地区、单权重20题不证明地理泛化或稳定目标图利用，也不升级默认。

配置和活跃会话仅当前服务内存；刷新页面需重新选择会话，重启服务不会自动续跑未封存作业。日志在磁盘保留，恢复前先检查绑定/终局/seal；不得盲目重跑已冻结对照。暂停不会中断已发出的单步请求，停止同样在当前一步完成后生效。

本轮Gemma对照完整20/20：M0 17/20、SG75米；Cloud6/20、SG795米，178请求/0失败/0回退。总真实请求179（含1双图接口），仍在预登记上限内。不同策略开发比较，不是同策略模型能力因果结论。

验收入口在核验与审阅目录；新中期Word见总结报告相关/平台交付_v1。按用户确认的三项范围完成即可收束中期平台开发，最终课程验收仍由教师要求决定。多Agent与新域/大网格训练研究留后续。
