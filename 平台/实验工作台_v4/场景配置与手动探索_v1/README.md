# GeoNav4.9：自由场景配置与手动探索

当前发布增加“场景仿真”入口，使用同一无GUI内核创建自由场景、手动移动、切回Agent、保存重开和同题过程比较。原4.8实验创建/批量/API/回放/试跑保存继续可用；地面照片仍是研究中，不开放未验导航。正式地址由发布核验记录确定，唯一启动器仍是平台/启动平台.cmd。

## 使用

1. 打开工作台，点击“场景仿真”，或访问 http://127.0.0.1:8769/scenes 。已有上传影像先在原工作台登记，随后在这里选择。
2. 选择影像、区域，填写起点格、目标格、预算和冻结权重。网格来自实际影像，不生成假的15×15；当前为航拍目标。预算允许1到已登记适配上限（5格通常10，10格20），不扩大冻结模型输入范围。预算不足最短路径会明确提示。
3. “创建临时场景”从起点开始。点击方向按钮手动移动，不调用模型；越界原地并耗一步，最后一步到达优先成功。每步展示观测与路径。
4. “切换Agent”后，可走一步或自动完成当前题；暂停停止后续动作。人工走过的合法历史按时间顺序补入策略记忆，不读取未来图块；历史同步会计入策略调用数，不计作新移动。运行中不能更换方案，另跑同题才可换。
5. “保存场景配置”只保存小型配置，复用影像，不复制数据。运行完成/失败/结束后“保存本次结果”，刷新或服务重开后可只读打开，也可导出JSON。未结束的模型内存不伪装成可恢复状态。
6. “从起点另跑同题”新建临时运行，原记录不改。两次同场景可比较；含人工的记录标为人工/人机接管，不计入算法SR或恢复损伤。人工已知起终点或查看全图，不能称人类盲测基线。

全图开关仅用户可见，模型始终只接当前观测/目标和真实访问历史。没有地理尺度时仅报告格数；用户上传的尺度仍是用户声明，不升级为地理测量。自由场景与正式冻结队列分账，旧科研默认/验收不改变。

## 验证与证据

- [15项合成检查](合成测试.json)：权限/非法字段/预算/末步成功/边界耗步/手动零模型/人工接管历史/分账/保存重开/故障隔离/租期。
- [首动作绑定](首动作绑定.json)：同一已消费Masa S3题，最多2轨迹20步。实际人工1步后M0接管共4步，另纯M0同题4步，共2轨迹8动作/8策略调用（含1次历史同步）。没有新增科研SR。
- [另一几何和原日志复核](真实交互与另几何复核.json)：动作/位置一致，Agent概率差在1e-6内；手动无模型调用，人工不纳入算法配对。相同Agent另实现，不是独立人员评审。
- [GUI](浏览器验收.json)：创建→手动→接管→终题停→保存→纯Agent同题→分账对照，刷新与服务重开只读成功。桌面1280×720、390×844窄屏无整页横溢出、格子正方形；观察者全图25/遮挡5图，步数保持4。截图见审阅/。
- [HTTP/同源/令牌](HTTP与发布预检.json)、[旧输入与用户文件保护](原件保护.json)。工程记录独立在本批工程工作区，没有导入正式用户库。

## 范围与恢复

本轮只实际验证Masa5×5/B10、M0、seed0。其它已接入5/10格数据和上传数据复用适配器，不能据此称其新自由预算已经完成真实导航验收。方案限M0及原数据已支持的Frontier；本页暂不调用Cloud，原工作台API入口保留。任意预算扩大、其它模态、3D动力学和重启恢复未结束运行不在本批。

默认临时场景/运行离页释放（180秒超时兜底）；显式保存的场景和终局记录持久保存。新输出在工作台store/scenes下，写盘先临时文件再原子发布；写失败原址保留，不进入正式目录，不自动删历史。已经保存的快照不可覆盖更新。

首次候选在沙箱监听但主机超时，0导航后用自有停止文件关闭，另受限传输恢复入口才执行两条真实轨迹；对话切换后该子进程退出，保存结果完整，另只读服务补验，所有创建/模型/导航拒绝。不能重跑旧serve/transport或再次导航补截图。

源码在project/src/platform_core/scene_workspace_v1.py、service_v7.py及webapp/workbench_server_v13.py；旧4.8核心/GUI是明确依赖，原源码仍保留。启动器与文档旧字节映射见入口更新映射.json。当前单一搬迁工具为package_workbench_v13，只按需打包；本批仅保存清单，不堆积完整ZIP。0训练/新编码/云模型API/6确认/外网或代理/新C盘输出/提交推送Git。

恢复先查正式部署核验、阶段封存、保存记录及当前进程。已消费的prepare/serve/transport/audit-save/close与GUI动作不重复；只读SHA/JSON可复核，无需重跑模型。
