# 使用工作台4.8保存试跑并做同题对照

1. 双击项目根下`平台/启动平台.cmd`，进入“创建实验”。选数据、题目、方案和冻结权重。默认临时模式，创建后点击“整个任务”执行队列；“当前一道题”仍只执行所选题并暂停。
2. 试跑结束后，在“保留这次结果，接着做同题对照”中点击**保存为正式实验**。新正式ID保留原每题动作、轨迹、结果、指标和原模型绑定，不重新运行。原临时记录不改，重试保存不会生成重复副本；原临时副本在退出页面时释放。
3. 在正式原实验中选“对照方案”，点击**按原题新建对照**。题目、顺序、格网、行动预算和权重集合固定，只改显式选择的策略；新对照默认临时，尚未执行。选择原策略时按钮显示“同题复跑”。不支持的策略不能选，Cloud未配置时不能直接用。
4. 运行新对照。完成后点击**刷新对照**，查看两次实验的完成数、SR、SG和同题恢复／损伤；未完成题不被计作已完成配对。原实验多方案时默认以第一方案作为基准，原有同实验多策略对照仍保留。
5. 需要留档的新对照也点击**保存为正式实验**。刷新/重开页面或服务后，在“实验记录”打开，原实验关联和结果仍存在；浏览/刷新对照/导出不调用模型。

**暂停与未完任务**：本版不搬迁正在运行或暂停中的模型内存。请完成队列，或明确点击“结束实验”后保存。单题按钮完成后仍显示暂停时，可继续剩余题，或结束整份实验再保存；结束不把未跑题伪装为完成，SG仍等待完整队列。尚未开始的ready试跑也可先保存为正式记录后再运行。

**存储失败**：保存先写`store/.pending-experiment-*`，校验后原子提交到正式实验目录。写盘失败时原试跑保留，未完成暂存不进入实验列表；服务能力信息报告待核查数量。不要直接删历史或盲重跑模型补保存。

**结果含义**：SR按原计划题数计；SG为全体终局格距离，尺度未知不伪报米数；两个记录必须题目/预算/种子集合一致且公共输入SHA一致才配对。这里是开发或自由试跑，不能替代原正式验收，也不自动升级M0。地面照片导航仍未准入，不能把地面已存分数诊断称主动定位。

**迁移与恢复**：唯一启动入口为`平台/启动平台.cmd/.ps1`；按需运行`project/src/tools/package_workbench_v12.py`，不长期堆积完整ZIP。CLI_v4保留原导航/地面命令；新保存与对照目前通过Web或Python内核调用，不宣称已有新的CLI子命令。4.7旧入口字节和SHA映射在本批`入口快照/`与`入口更新映射.json`，回退先查实际作业/store锁，不能直接运行归档PS1或同时写同一store。
