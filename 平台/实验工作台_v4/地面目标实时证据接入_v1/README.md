# GeoNav4.10：实时地面编码与局部证据

**平台工程已完成。** 新入口 http://127.0.0.1:8769/ground-live ，也可从场景仿真导航进入。保留既有航拍/手动/批量/API/历史地面诊断，当前唯一启动器为平台/启动平台.cmd（server_v16/service_v9），旧4.9.1模块是兼容依赖与复现证据。

## 使用

1. 载入已消费开发示例，或选择给定地面照片与当前局部航拍图；输入仅在点击编码后送本机。
2. 点击“开始实时编码”。独立CPU进程依次严格加载冻结CLIP/Sat2Cap，每次最多2个单图forward，4GiB采样RSS/180秒护栏；可取消，不并行加载，不自动重试，不下载或调用云端。
3. 查看实际224×224 RGB输入、512维特征状态、原始余弦、冻结权重与资源回执。地面按原缩放/中心裁剪、航拍按原方形缩放，传输几何与原预处理逐像素等价，元数据去除。原始全尺寸图不作为结果副本保存。
4. 结果默认临时，离页释放；显式保存后进入本机只读记录库。可重开或导出含两张实际编码图、特征/模型/源码/资源绑定的JSON，均不再调用模型。保存异常保留.pending目录并隔离提示，重存幂等，不覆盖旧结果。

保存记录为`store/ground_live/<id>/record.json,target.png,current.png`，不混入导航成绩。默认store是DATA/processed_data/平台实验/工作台_v1；新未知照片自由编码只是工程体验，不能变成正式确认结果。保存记录供本机页面只读查阅，临时输入归所属页面会话隔离。

## 结论边界与迁移

raw_similarity仅未校准证据，confidence=null；本模块不选择移动方向、不执行环境、不读取目标索引/位置答案或候选库，navigation_available=false、SR=null。地面闭环研究未过结论保持，不复活CV024失败策略；没有新训练、导航、云API、下载或6确认消费。

GUI只是GroundLive内核的呈现，Python可独立调用create/state/save/catalog/image。独立worker只接两张清理后的RGB图，无环境句柄、源身份或整图特征库。当前单一打包器package_workbench_v17.py；默认轻量清单不带原始数据/凭据/编码骨干，目标机缺资产时页面明确提示且仍可看已存记录。需要自包含编码时由使用者显式加--with-ground-encoders，复用已有资产，不自动下载。本轮仅生成清单，不堆积ZIP或模型副本。
