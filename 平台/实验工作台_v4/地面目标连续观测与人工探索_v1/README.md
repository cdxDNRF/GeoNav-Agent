## 使用

选择已登记5×5配对开发场景、名称和预算，创建临时探索。地面目标固定为本场景配对照片，编码一次；初始和后续仅当前航拍图传给编码器。人工上/右/下/左选择方向，越界原地并耗一步，正在编码时等待；首次到数据代理格优先结束，最后一步到达同样算到达。

地图默认遮挡未访问格；观察者全图只显示，不进入编码请求或访问记忆。重访当前像素复用本题缓存，不再forward；跨次探索目标与缓存清空。原始余弦只是证据，不是动作建议或位置概率。结束后可保存只读过程，重开不编码；导出携带目标/已访小图、逐步特征、动作与源码/模型绑定。保存仅携带已观测图片，缺原始场景也可重放这些图格。

记录为`store/ground_walk/<id>/record.json,goal.png,view-<cell>.png`。默认临时，离页/取消/租期释放；保存经临时目录提交和SHA核验后释放内存。编码按需独立CPU子进程运行，单图后退出，空闲时不驻留模型。会话最多600秒、单图180秒/采样RSS4GiB；方向没有自动重试。未结束会话不承诺服务重启恢复，旧已保存过程始终只读。
