## 可以做什么

1. 按地面目标来源2/3、拍摄点在格内/同源格外/异源关系筛选20个开发案例。
2. 切换真实/禁用/均值/错误目标，读取80条封存预测；错误目标显示实际替代照片，禁用/均值照片注明仅供任务说明。
3. 对照地面照片与唯一可见125×125航拍格，查看预测点、真实拍摄点和米数误差。真值只供事后观察，负例不虚构图内真值。
4. 查看保存的定位热图、匹配分数、阈值、四条件总体表、必要门槛和逐条SHA绑定；导出当前案例JSON。
5. 返回地面人工探索或航拍场景继续交互。查阅本页不会编码、预测、移动或生成科研成绩。

CV031的联合正例仍0/2，检测BA67.50%，候选已收束，无自主导航准入。两个来源为已消费开发组，来源宏BA是接受/拒绝指标，不能当定位准确率或导航SR。全拒绝基线66.67%；热图颜色是本图相对强度，不是存在概率。旧M0/S2/S3/S4验收保持。
