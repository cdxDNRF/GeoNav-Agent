当前 **GeoNav V5.0 / server28 / service17**。唯一启动对：[启动平台.cmd](启动平台.cmd) / [启动平台.ps1](启动平台.ps1)，默认打开 `http://127.0.0.1:8769/`（已内置端口等待与绕过系统代理检测，消除冷启动白屏）。
架构规划文档见：[平台 V5.0 一体化重构与功能全景规划](平台V5_一体化重构与功能全景规划.md)。

## 一体化六大工作台（无 Emoji 学术风 · 旁侧 `!` 气泡说明 · SPA 零跳转）

| 工作台标识 | 名称 | 核心能力与后端引擎映射 |
|---|---|---|
| `overview` | **平台总览与向导** | 紧凑一屏指标条、四大黄金场景一键预设、六大核心协议总表（点击 `!` 查看详细消融结论）、资产状态与 5 步交互演示向导 |
| `navigator` | **统一探索控制台** | 内置 **多源精选交互推演（192 张独立航拍底图 960 题 + 192 地面题、一键随机换图、鼠标点选起终点、小眼睛人类盲视全图预览、四向决策倾向度条）** 与 **标准封存审计 A/B 回放** 双子视图（`/api/v5/interactive/*` & `/api/controllers/*`） |
| `sandbox` | **自由场景与接管沙箱** | Masa S3 / 连续大区域自定义起终点与预算、5×5 或 10×10 网格 + SVG 轨迹折线、人工探索与 Agent (M0/Coverage3Radial) 历史同步接管（`/api/scenes/*`） |
| `arena` | **队列批测与API打擂** | 固定十题本地 M0 vs Frontier vs 云端大模型同题对照（`/api/api-comparisons/*`）+ 自定义小队列同题成对批测（`/api/controller-batches/*`）+ 顶部一键在线配置云 API |
| `ground` | **地面连续探索与编码** | 固定地面目标人工连续观察（`/api/ground-walk/*`）+ 单对地面-航拍 512 维实时冻结编码器诊断（`/api/ground-live/*`） |
| `evidence` | **空间感知与证据显微镜** | CV031 CCVPE 20 固定案例热力图与拒绝筛查（`/api/perception/*`）+ CV041 三城市 150 案例 7×7 空间小头多方法对照（`/api/spatial-evidence/*`） |

## 顶部全局交互能力（V5.0 与 Lite 同步提供）

1. **纯内存多尺度自定义图片切片（`3×3 ~ 10×10`）**：顶部点击【自定义切片】上传任意本地图像并实时切分，仅在当前服务内存存活，关闭即销、绝不污染样本库；
2. **云端多模态 API 在线配置与自检**：顶部点击【云端 API】支持在线设置 DeepSeek / OpenAI 兼容接口、一键【测试连通性】及勾选“关闭长思考输出（`thinking={'type':'disabled'}`）”防 `max_tokens` 截断。

## 极简演示平台入口 (GeoNav Lite 演示小平台)

若需面向导师或评审专家进行**无门槛、零心智负担的轻量单屏快速演示**，可使用独立解耦的 **GeoNav Lite 极简演示工作台**：
- **启动脚本**：[启动极简演示平台.cmd](启动极简演示平台.cmd) / [启动极简演示平台.ps1](启动极简演示平台.ps1)
- **独立端口**：默认运行在 `http://127.0.0.1:8768/`（与全功能 V5 平台端口 `8769` 完全隔离，通过 `_LiteWorkbench` 彻底解耦重型科研模块）
- **核心特色**：内置 **192 张独立航拍底图（960 道合格题，单图至多 5 题）+ 192 道地面拍摄点样本**，支持一键随机换图、网格点选起终点、小眼睛人类全图预览（盲视隔离）、`3×3~10×10` 纯内存自定义切片及 DeepSeek 兼容自检。
- **独立便携交付包**：[demo/小型演示demo.zip](../demo/小型演示demo.zip)（解压双击 `启动小型演示demo.cmd` 即开，详见 [极简演示平台文档](极简演示平台/README.md)）。
