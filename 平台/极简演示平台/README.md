# GeoNav Lite 极简演示平台

面向导师答辩汇报与组员日常演示的**单屏清爽视觉导航演示台**。

---

## 核心特性

1. **清爽单屏交互风格**：界面简洁克制、零冗余干扰图标，左侧为互动式网格地图，右侧并排展示【给定目标图 vs 当前实时视野】、核心指标与 AI 决策透视。
2. **多源精选航拍题库 + 全量地面样本库**：
   - **192 张独立航拍图像 · 960 道实测合格预置题**（覆盖 Masa S2 验证集 4 图 20 题、Masa S3 独立源 10 图 50 题、SwissView 瑞士两批 40 图 200 题、MassGIS 5×5 & 10×10 区域扩展 5 题、Masa 大规模扩展图库 137 图 685 题），**每张底图严格只精选至多 5 个经 M0 验证通过的代表性起终点**，不硬堆重复题，支持顶部一键【随机换图】；
   - **192 道地面 OpenCVL 拍摄点任务** 完整保留；
   - **更换样本即时清理**：切换下拉题目瞬间清除上一道题已翻开的图像方块与推演记录，方便直接在干净地图上点选起终点。
3. **小眼睛整图预览功能（仅人类观察可见）**：
   - 点击地图右上角【预览全图 / 关闭预览】，即可无遮挡浏览完整底层拼接大图；再次点击恢复局部迷雾。
   - **严格隔离保证**：全图预览仅用于人类观察与挑点，底层智能体保持盲视。
4. **自定义图片多尺度切片与纯内存临时隔离**：
   - 点击右上角【自定义切片】，支持将本地图像实时切分为 **`3×3`、`4×4`、`5×5`（推荐最佳）、`6×6`、`7×7`、`10×10`** 多种规格，并在预览图上实时显示虚线切分线；
   - 所有自定义上传切片仅缓存在本次服务内存中，关闭或重启后端自动销毁，绝不污染测试样本库。
5. **多策略支持与云端连通性透明诊断**：
   - **本地 M0 视觉智能体**：目标边缘线索门控 + GRU 拓扑探索（`10×10` 等大尺度自动激活 H=3 前瞻覆盖规划）；
   - **人工遥控**：方向按钮、点击相邻格子或键盘 W/A/S/D / 方向键；
   - **云端多模态 API**：支持 OpenAI 兼容格式与模态弹窗【测试连通性】自检，并精确报告 HTTP 状态码（如 402 余额不足 / 401 / 超时 / JSON 格式偏差）；
   - **Frontier 基线**。
6. **独立端口互不干扰**：默认监听 `8768` 端口，与 GeoNav V5.0 全功能平台（`8769`）完全隔离。

---

## 启动方式

- **Windows 双击即开**：双击 `平台/启动极简演示平台.cmd`
- **PowerShell**：`powershell -ExecutionPolicy Bypass -File 平台/启动极简演示平台.ps1`
- **命令行**：`D:\PYTHON\python.exe project/src/webapp/lite_server.py --port 8768`
- 浏览器访问：`http://127.0.0.1:8768/`
