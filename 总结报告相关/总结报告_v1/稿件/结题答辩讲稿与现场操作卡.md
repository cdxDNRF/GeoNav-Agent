### 第二部分：核心方法一 —— 航拍 M0 架构（Slides 07–11，约 2 分钟）

- **Slide 07（航拍四阶段研发演进）**  
  我们的航拍方法经历了四次清晰跃迁：从耦合特征拼接的 `73.0%→74.4%`，到引入拼缝边缘线索跃升至 `81.0%`，再通过探索与识别分支解耦结合四条件门控突破至 `89.33%`，最终免重训推广到 `9km²` 连续大区域取得 `68.04%`。

- **Slide 08（M0 双分支显式解耦架构）**  
  图 1 展示了 `934,538` 参数的完整机理：左侧 `Small256` 循环探索器（`797,701` 参数）只负责最大化覆盖探索，绝不接触目标纹理；右侧 `Edge` 线索头（`136,837` 参数）专门提取当前格四边与目标图拼缝的 20 维像素连续性，一旦高概率命中邻接关系便触发条件门控直接锁定步进。

- **Slide 09（真实航拍任务逐步决策解剖）**  
  以真实验证样本 `val_000_b10_g13_s04` 为例，前两步依赖探索器避开已访区域向未知拓展；到达临界格 `(1,3)` 时，下边界拼缝线索打分骤升至 `q(下)=0.86 ≥ 0.50`，门控瞬间接管并精准一步迈入目标格 `(2,3)`。

- **Slide 10（四大协议 16,200 轨迹四条件消融）**  
  为证明成功确实来自对目标图视觉线索的真实利用而非地图死记硬背，我们在 `Masa S2/S3/S4` 与跨大洲 `SwissView` 四大协议共 `16,200` 条轨迹中均设置了真实/禁用/均值/错误四类目标对照，真实目标条件 `CueFull` 在全部协议稳定大幅领先（例如 `Masa S3` `86.80%` 对禁用目标 `73.60%`、均值目标 `73.20%`、错误目标 `69.47%`）。

- **Slide 11（步数收敛效率、6,000 轨迹对比与参数拆分）**  
  将 S2 动态曲线与 S3 参数效率合并看：20 维手工边界特征独立贡献了 `+8.33%` 的成功率（`89.33% vs ZeroEdge 81.00%`）；在 `Masa S3` 与 `GeoExplorer` 的 `6,000` 轨迹同题对标中，M0 领先 `+51.20` 个百分点且 `SwissView` 跨区域稳定保持 `86.80%`。

### 第三部分：核心方法二 —— 9km² 大区域覆盖规划（Slides 12–13，约 1 分钟）

- **Slide 12（Coverage3Radial 三步前瞻与径向保护机制）**  
  当尺度扩大到 `10×10` 每格 `300m`、总面积 `9km²` 的连续真图时，单步探索易在局部凹区打转。我们在不重训任何网络权重的前提下提出 `Coverage3Radial`：利用 `H=3` 步前瞻路径最大化未知格信息增益，并施加仅基于公开起点的径向非递减保护防止无效回撤。

- **Slide 13（MasaRoads 十区全正增益与 MassGIS 异源边界）**  
  在 `10` 个空间隔离测试区共 `2,250` 条配对轨迹上，`Coverage3Radial` 将 `SR` 从 `58.84%` 提升至 `68.04%`（`+9.20%`），`10/10` 区域全部实现正增益，净恢复 `207` 道任务；在跨传感器 `MassGIS` 上，`5×5` 网格稳定过线（`85.47%`），而 `10×10 (54.62%)` 与 `15×15 (20.27%)` 受色差漂移及 `21.29%` 首步同向翻转影响未达 `60%` 预设门槛，我们如实将其界定为当前适用上界。

## 三、 高频评委提问（Q&A）标准答复口径

1. **Q1：既然云端大模型（31B）也能看图推理，为什么不直接全部交给云端大模型？**  
   **A**：我们在固定十题队列上做了同题全链路审计（`96` 次 API 请求、`537.08 秒`、`71,005 Tokens`），结果 `Gemma-4-31B` 仅解决 `1/10`（`10.0%`），出现 `54` 次原地重访和 `24` 次越界撞墙；原因在于通用 VLM 缺乏“拼缝边缘像素级连续性”与离散网格记忆先验。因此本地 `0.93M M0`（`80.0%`、`<10ms`）作为默认主策略，云端 API 仅保留在可控比对与安全熔断体系中。

2. **Q2：跨视角地面照片（OpenCVL）阶段二最终没有通过预设门槛，是否影响课题完整性？**  
   **A**：不影响，反而恰恰体现工程与科学实证的严谨性。我们在 `CV-048~051` 中通过 `1,653` 次受控前向率先定位并拆穿了切分混杂（`4:3→16:9` 从 `40.5%` 跳至 `87.9%`）与无图像先验地板（`42.24%`）两重统计假象，在发现 `M2c` 跨城 `dev_val`（`24.14%`）弱于均值视觉消融（`42.24%`）后严格执行止损停训，使 `28` 对全隔离盲测集保持 `0` 解码、`0` 评测，完整保留了真实负结果与理论归因。

3. **Q3：如何保证你们演示平台现场切换不会卡顿或泄露答案坐标？**  
   **A**：架构层面采用 `service_v17` 隔离评测，前端“小眼睛全图预览”仅面向评委 UI 渲染，策略模块 `Observation` 严格剔除 `p*` 与真实距离；平台默认跑在本地 `0.93M` 轻量核，断网条件下毫秒级推演，并已完成 `V5.0 (6/6)` + `Lite (6/6)` 自动化回归与 `2026-11-14` 无外网实机预演。
