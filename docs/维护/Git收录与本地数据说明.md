# Git收录与本地数据说明

本仓库发布当前平台、有效研究机制源码、关键报告/判定/协议和当前图表。Git克隆不等于取得全部实验输入，也不是开发机文件夹的完整备份。[本轮公开范围](../../项目导航/Git精简发布_20261025_v1/README.md)和公开文件清单给出具体边界。

| 内容 | GitHub当前树 | 本地处理 |
|---|---|---|
| AGENTS、当前README/状态、TASKS/HANDOFF | 保留 | 当前可维护入口 |
| 当前平台代码、实际导入/继承依赖、必要静态资产、CLI/测试 | 保留 | 旧编号内部依赖不等于多套发行版 |
| 冻结科研执行机制、关键报告/验收/汇总/协议/哈希 | 筛选保留 | 全部详细原件仍在本机；未公开来源有明确记录 |
| 当前中期/总结Word与PDF、科研图 | 保留当前稿/有用格式 | 草稿、排版校样及审阅过程仅本地 |
| 旧V2/V3/上传台整套资料 | 不收录 | 唯一37份验收资料移入平台/历史版本对应目录，SHA映射留本地 |
| 完整旧队列回放工具 | 不收录 | 有独立历史用途，仅本地保留，不是当前平台 |
| 原始影像、模型/特征/数据库、逐步轨迹/预测、源码快照副本 | 不收录 | 按保留级别留本地，不因退出Git删除科研原件 |
| 临时验收工作区、入口备份、外部助手资料、参考论文PDF、视频素材 | 不收录 | 本地留存或按已授权清理，论文提供公开来源链接 |

公开代码有些带旧版本号，是当前导入/继承或科学复核依赖；不能按最大编号删除。新发布先运行选单工具核依赖、原件与文件体积，再暂存明确清单，禁止git add .整树上传。新实验/新版本应登记后更新公开文件选择，不能假定新目录自动收录。历史失败开发稿不作为当前可运行入口。

新克隆运行前：先配置兼容Python/依赖，再按对应绑定取得官方数据、本地权重、均值/缓存并核SHA；旧JSONL/原图不在Git时，页面应提示缺失，不能重预测冒充原结果。当前启动方式见[平台](../../平台/README.md)。完整科研重跑和另一台机器全功能验收仍有缺项，不把源码语法/合成检查替代模型效果。

所有清理/迁移以最新保留记录为准。2026-10-12已永久删除105旧中间TIFF及部分旧权重的恢复副本，不能再引用早期“可从7z恢复”的旧描述；三份最终基线权重仍留本地。2026-10-25仅移除已核可再生环境/副本，唯一内容另保。[永久清理](../../项目导航/归档永久清理_20261012_v1/README.md) / [本轮存储收束](../../平台/实验工作台_v4/发布修复与存储收束_v1/README.md)。

本次为普通提交和SSH推送，不强推、不改写旧提交。退出Git索引不删除本地文件，旧对象仍可能存在于历史提交；当前检出体积和完整克隆历史体积是两件事。凭据、.env、私钥永不收录，仅保留占位示例。
