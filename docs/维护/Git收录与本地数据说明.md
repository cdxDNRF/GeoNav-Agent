# Git收录与本地数据说明

本仓库是代码、研究报告和小型追溯材料的精简发布。完整数据、模型及逐步记录仍保存在开发机，不能把Git克隆等同于已经取得全部实验输入。

## 公开与本地分层

| 类型 | GitHub收录 | 本地位置与理由 |
|---|---|---|
| 长期规则/任务/交接/当前状态 | 保留 | 根AGENTS/README、.agents核心入口、docs/PROJECT_STATE |
| 研究/平台源码、测试、协议配置 | 保留 | project/src及project/defaults；不改变历史执行代码 |
| 方案、任务清单、报告、判定、汇总、seal、输入/源码SHA | 保留 | DATA原批次与研究/材料目录；可追溯各自分母和验收 |
| 科研图、课程材料和少量最终展示图 | 保留 | 绘图、中期报告相关、平台审阅及视频最终海报 |
| 接手提示、外部助手说明/配置/运行回执 | 不收录 | .agents/本地；保留供本机顺序接手 |
| 外部助手临时/历史工具脚本 | 不收录 | project/src/tools/local/archive；与导航Agent代码分离 |
| 原始影像、模型、特征缓存、原生TIF/TIFF | 不收录 | 原路径保留；体积大，另按官方来源和冻结清单准备 |
| DATA逐步轨迹/预测/探针JSONL | 不收录 | 原路径保留；保留任务、汇总、seal与SHA，不删除成功/失败证据 |
| 小型JSONL任务清单、方向视图来源JSON | 保留 | Masa两版episodes及云端冻结任务、视图来源；不按扩展名把计划任务当逐步轨迹 |
| 大批视频帧、工程缩略图、开发缓存 | 不收录 | 原路径保留；按对应制作入口生成或从本机取得 |

Gitignore不会自动取消已跟踪文件。本次只用`git rm --cached`取消收录对应逐步JSONL和可再生视图图片，磁盘文件原址、字节、SHA保持不变；没有移动大数据或模型。失败方案、审计历史版本及源码快照不按“冗余”删除。

## 工具资料迁移与历史复核

本机`.agents/`只保留核心入口和明确的归档/本地子目录；`docs/`根只保留当前状态及阶段计划。外部Agent/Pi说明原件迁至`.agents/本地/工具说明/原件/`，可阅读副本使用新路径。两接手提示迁至`本地/接手提示/`，工具批次迁至`本地/工具记录/`。六份助手脚本原字节归档至`project/src/tools/local/archive/`；研究源码及科学批次原件不动。

Pi旧说明和部分工具源码曾被历史保护清单记录。本次保存87份迁移文件的原路径→新路径/SHA映射，并按原SHA核验迁移后原件。科学执行输入与研究源码没有改动，旧报告、验收和保护清单不回写。后续复核工具原件时，先查本地`文件迁移映射_v1.json`，按新路径核对**原SHA**；本次核验工具支持`resolve_moved`做严格映射。若需运行旧工具脚本，应先依据清单恢复其旧路径或另写适配新版本，不能把归档脚本直接当当前接口。

历史报告链接可能引用仅本地保留的影像、完整JSONL或旧工具路径；在GitHub上这些链接不代表缺失研究汇总。真正逐条重算需要原输入，不应仅从汇总生成新结论。当前运行和恢复入口见[项目状态](../PROJECT_STATE.md)、[实验索引](../../项目导航/实验索引.md)、[平台说明](../../平台/主动探索演示_v1/README.md)。

## 克隆后的运行前提

1. 安装对应依赖；本机现有Python位于D盘，不要求额外安装Ollama。
2. 按实验索引/数据工程冻结清单取得相应官方数据、本地权重、均值和特征；核对SHA、空间范围与任务身份。
3. 回放平台需要原封存JSONL和图块。GitHub包含界面/适配代码及小型核验结果，本身不包含这些大体积输入。
4. 不直接重跑已封存prepare/index/导航/报告生成器；新运行另立任务与输出版本。
5. 凭据和.env仅本地保留，不从仓库文档中取实际key。

本次发布采用普通提交和SSH推送，**不重写历史**。当前版本取消跟踪大文件后会更轻，但以前提交中的大对象仍留在Git历史；若将来需要缩小完整克隆，应另行授权历史清理或迁移存储，本次不执行强推或Git GC清史。
