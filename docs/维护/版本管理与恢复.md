# 版本管理与恢复

当前为 **4.18 / server27 / service16 / pack33**。唯一启动对：[cmd](../../平台/启动平台.cmd) / [PowerShell](../../平台/启动平台.ps1)。[操作说明](../../平台/实验工作台_v4/单模型API统一接入与同题对照_v1/使用与恢复.md)与[生命周期](版本生命周期.json)是当前入口，历史文字中的“当前”只适用于当次交付。

| 角色 | 保留与运行方式 |
|---|---|
| 当前使用 | 单一启动对、`workbench_server_v27`、`service_v16`、`package_workbench_v33`、按协议冻结默认 |
| 当前依赖 | `server_v3..v4`、`live_v2..v4`、`workbench_server_v6..v12`、`service_v2..v15`、原导航/API适配器等运行闭包模块；不凭旧编号盲删运行依赖 |
| 历史版本与淘汰文件（`归档/`） | 已被新版替代且退出当前运行闭包的旧版源码、早期工作台批次（v4.0–v4.14）、旧报告草稿与过程审阅统一按 `<项目根目录>/归档/<原相对路径>` 镜像存放，清单见 [归档清单](../../归档/归档清单_20261108.json) |
| 一次性脚本与临时区（`temp/`） | 一次性生成脚本、调试代码、临时中间文件统一放 `temp/`，随时删除不影响项目 |
| 研究原件 | `DATA/`、`models/` 中的模型、任务、预测、轨迹、判定、来源账本及失败证据；按角色原址保留 |

本轮替代4.13启动入口；旧4.12和pack23的current状态已收束。此前版本迁移和27.08GiB永久清理依然有效，见[20261012记录](../../项目导航/归档永久清理_20261012_v1/README.md)。三份基线最终权重仍留在冷存储，旧模型是否退役另行决定。

本轮[入口原字节与清理映射](../../平台/实验工作台_v4/发布修复与存储收束_v1/README.md)保留old/new/SHA。旧便携副本可按清理清单的restore_source/retained重建；旧Python环境仅有安装元数据，重新安装不保证字节级环境重现。本轮不安装包、不下载、不生成完整ZIP。原封存保持当时事实，不为清理回写旧seal。

恢复旧入口前检查活动实验，不能停止未知进程或覆盖用户记录。只恢复所需单项，先核SHA；不能从归档位置直接运行旧硬编码脚本。旧生成器不得覆盖用户Word/PPT。新版本必须更新当前入口、生命周期、依赖、验收和回退入口；不能只新增版本号。

整理前本说明的完整迁移表/原规则字节见[旧说明快照](../../平台/实验工作台_v4/发布修复与存储收束_v1/入口快照/03.before)，其相对路径按原docs/维护目录理解。
