## 当前定位

项目研究主动探索视觉地理定位：智能体获取给定目标图与连续局部航拍视野，在行动预算内选择探索方向并到达目标。已完成环境、统一评测/日志、云端VLM接入、本地训练策略、正式S2/S3和多项扩展验证。

**本轮PLATFORM-002三项平台交付已实现，中期平台开发具备收束条件。** [进度复查与平台计划](项目进度与平台交付计划_v1.md)区分可演示回放V0.1与实时运行V0.2；MassGIS15×15作为未通过的扩展研究保留，不再阻塞课程平台建设。EVAL-004诊断和v11复核已完成；EVAL-002两网格Coverage SR54.62%/20.27%仍未过原门槛，10个正式区已消费、3个备用区未参与。坐标归一化、25桶访问布局与训练网格错配是有证据支持的贡献机制，不是因果证明；坐标格点适配草案未启动。默认、模型、阈值及历史验收不变。

开发可以由Codex、ZCode等多个Agent协作；算法本身仍是训练过的单导航Agent及规则模块。两者不能混为一谈。真正导航多Agent协作尚无足够收益证据，当前不扩大该支线。
