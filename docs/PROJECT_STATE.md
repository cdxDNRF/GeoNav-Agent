## 当前维护与下一步

本轮按清单移除旧干净环境、旧Geo缓存和旧便携工作副本的可再生内容，唯一内容已保全；本机逐文件清理预登记（仅本地保存，不随Git）记录路径/SHA/恢复来源。模型、三份基线最终推理权重、原始数据、历史科研源码/结果与用户记录保留。旧封存不回写为仍可直接恢复；重建旧副本必须先按SHA映射核所需单项。

研究候选继续收束。后续研究须先取得任务匹配的空间监督/可辨识性证据，再冻结一个轻量因素；不自动训练或消费确认组。平台继续完善便捷运行、结果解释和迁移，不等待所有研究问题解决。
