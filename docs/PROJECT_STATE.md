# 项目当前真实状态

更新：2026-10-03。这里维护当前事实与主线；执行规则见[AGENTS](../AGENTS.md)，谁在修改哪些文件见[任务表](../.agents/TASKS.md)，恢复/交接见[交接簿](../.agents/HANDOFF.md)。阶段数与结论以原批次证据为准；本文摘要不是实验原件。

## 当前定位

项目研究主动探索视觉地理定位：智能体获取给定目标图与连续局部航拍视野，在行动预算内选择探索方向并到达目标。已完成环境、统一评测/日志、云端VLM接入、本地训练策略、正式S2/S3和多项扩展验证。

**主线是实际搜索面积扩展：已确认9km²区域策略，正在为15×15、20.25km²准备真实数据。** 15×15目前只有参数化接口和合成验证，没有真实影像导航SR。当前目录池不足，需要先补足数据。

开发可以由Codex、ZCode等多个Agent协作；算法本身仍是训练过的单导航Agent及规则模块。两者不能混为一谈。真正导航多Agent协作尚无足够收益证据，当前不扩大该支线。

## 已实现的系统与默认入口

- 冻结Sat2Cap编码器；Small256 NoTarget GRU探索器；EdgeTargetCue视觉头；0.50置信阈值与合法、未访问方向门控。
- NoTarget只遮蔽探索器目标通道，视觉头仍使用给定目标图。系统有训练来源，不是整体零训练。
- Coverage3Radial在无已接受cue时执行三步覆盖候选，要求至少2格覆盖增益，并用公开起点径向距离保护原动作；已接受cue优先。
- 新物理区域入口：[默认注册表](../project/local_policy_defaults_v1.json)、[配置及加载说明](../project/defaults/README.md)、[加载器](../project/src/agents/area_policy.py)。已验证作用域仅MassachusettsRoads、300米/格、10×10/B20；默认参考seed0，M0可显式作对照。
- 原5×5及原跨数据集脚本继续使用[原M0配置](../project/local_policy_default.json)。登记新入口不代表所有历史脚本自动切换；旧脚本用于复现旧批次。
- 15×15需`allow_experimental=True`，只属工程候选，不能称已确认默认。模型参数、均值和0.50没有扩大或重训。

## 数据、消费状态与结论边界

- Masa：本地151源，137训练/4验证/10测试；探索器109拟合/28开发，视觉头87拟合/22校准。和论文1188张的差异未核实。
- SwissView100：100张航拍子集，累计68源已导航、32尚未；见[使用状态](../选题报告相关/SwissView源文件使用状态_2026-10-02_v2.json)。这些数量不自动说明地理隔离或物理15×15可用。
- 新15×15正式确认池须排除原151足迹及已消费24个新连续区域，并核验区域边界间隔。工程可使用消费区，不能混入正式确认。
- 原S4仅增加切图密度；9km²连续区域保持300米/格，属于实际面积扩展。15×15目标保持相同尺度，需9张原生源图组成3×3、4500×4500像素，面积20.25km²，不能拿放大或密切图替代。
- 当前缓存官方train目录1108项，经排除和已知缓存质量筛选剩47个文件名候选，最多可组合9个相互隔离区。这个上限只针对当前目录及筛选；真实GeoTIFF坐标和全部质量尚未验证，可用数量可能更少，不代表整个作者数据集仅有9区。[目录与打包复核](../DATA/processed_data/MasaRoads/工程准备/默认版本化与十五乘十五兼容_v1/目录候选空间打包复核.json)
- 当前结论限连续、同模态航拍切图仿真；Sat2Cap预训练地理范围未知。任意角度、真实异时、跨视角/跨模态、实飞和更大实际区域性能未确认。
