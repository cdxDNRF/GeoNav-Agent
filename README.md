## 目录用途与维护

| 目录 | 用途 |
|---|---|

| `课程相关报告模版/` | 只读教师模板 |
| `绘图/`、`论文/`、`调研/`、`视频/`、`GOMAA-Geo/` | 图表、参考与既有第三方工程；`视频/` 由用户自行维护，原件按其角色保留 |
