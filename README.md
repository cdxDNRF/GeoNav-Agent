# 基于主动探索的视觉地理定位方法设计与实现

智能体根据给定目标图与连续局部航拍视野，在有限行动预算内主动探索并定位目标。项目包含环境、评测与日志、训练过的本地单导航Agent和协议化扩展实验。

截至2026-10-03：300米/格、10×10/B20的Coverage3Radial已独立确认并登记协议默认；15×15仅接口兼容通过，真实20.25km²影像数据和导航成绩尚待验证。最新事实维护在[PROJECT_STATE](docs/PROJECT_STATE.md)。

## 开始协作

所有开发Agent先读[AGENTS.md](AGENTS.md)，再读[当前状态](docs/PROJECT_STATE.md)、[任务表](.agents/TASKS.md)和[交接簿](.agents/HANDOFF.md)。写入前认领范围，不改其它Agent正在修改的文件；任务表是协作约定，不是文件锁。workflows尚未启用。

## 运行与复现

在本仓库根运行，先核查已有依赖；本机Python为`D:\PYTHON\python.exe`。依赖入口：[基础层](project/requirements-foundation.txt)、[云端接口](project/requirements-vlm.txt)；本地主方法使用已有PyTorch/Sat2Cap，不要求安装Ollama。

从实验索引进入批次README、执行协议、判定与源码快照。旧脚本常已有同名输出，禁止直接重跑覆盖。新实验另立版本并在首动作前冻结；原始数据和凭据不进入共享产物。文档改动校验链接和迁移规则即可，不启动训练/导航。
