# 基于主动探索的视觉地理定位方法设计与实现

智能体根据给定目标图与连续局部航拍视野，在有限行动预算内主动探索并定位目标。项目包含环境、评测与日志、训练过的本地单导航Agent和协议化扩展实验。

本轮三项平台交付已实现：[实时导航/API/同题批量](平台/实时导航平台_v2/README.md)、[方法图与新Word总结](总结报告相关/平台交付_v1/README.md)；[回放V0.1](平台/主动探索演示_v1/README.md)保留。按用户确认范围可收束中期平台开发，教师最终提交要求另行核对。扩展研究的失败不取消已通过的历史验收。

截至2026-10-05：MassGIS新产品正式双网格确认仍未过门槛（10×10/15×15 Coverage SR 54.62%/20.27%）。EVAL-003与DEV-001已收束；EVAL-004只读诊断发现坐标归一化与25桶访问表示漂移是合理贡献机制，但不是因果证明，默认和正式验收不变。[EVAL-004补充报告](DATA/processed_data/MassGIS/评测结果/十五乘十五到达能力漂移诊断_v6/EVAL-004诊断与复核补充说明_v1.md)。原S2/S3/S4及MassachusettsRoads 9km²协议默认继续有效。最新事实见[PROJECT_STATE](docs/PROJECT_STATE.md)。

## 开始协作

所有开发Agent先读[AGENTS.md](AGENTS.md)，再读[当前状态](docs/PROJECT_STATE.md)、[任务表](.agents/TASKS.md)和[交接簿](.agents/HANDOFF.md)。写入前认领范围，不改其它Agent正在修改的文件；任务表是协作约定，不是文件锁。默认顺序接手，额度不足时按交接恢复；workflows尚未启用。

## 运行与复现

在本仓库根运行，先核查已有依赖；本机Python为`D:\PYTHON\python.exe`。依赖入口：[基础层](project/requirements-foundation.txt)、[云端接口](project/requirements-vlm.txt)；本地主方法使用已有PyTorch/Sat2Cap，不要求安装Ollama。

从实验索引进入批次README、执行协议、判定与源码快照。旧脚本常已有同名输出，禁止直接重跑覆盖。新实验另立版本并在首动作前冻结；原始数据和凭据不进入共享产物。文档改动校验链接和迁移规则即可，不启动训练/导航。
