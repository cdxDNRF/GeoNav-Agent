## 目录用途与维护

| 目录 | 用途 |
|---|---|
| `project/src/` | 英文小写源码目录；环境、策略、内核、Web、测试、工具与报告生成器 |
| `project/.runtime/` | 必要隔离依赖/第三方执行源；可再生环境按清单回收 |
| `DATA/raw_data/` | 只读原始数据，不随本轮清理 |
| `DATA/processed_data/<数据集>/` | 按独立批次保存派生输入、冻结配置、记录、指标和复核 |
| `models/` | 单份编码器与公开权重；不按普通缓存清理、不进入Git |
| `平台/` | 单一启动对、当前工作台说明及按批验收证据 |
| `项目导航/` | 实验索引、目录维护、协议与交付导航 |
| `docs/`、`.agents/` | 当前状态、稳定维护说明与协作记录；本地助手材料不进入Git |
| `选题报告相关/`、`中期报告相关/`、`总结报告相关/` | 按阶段和版本区分报告；不能用旧生成器覆盖用户稿 |
| `课程相关报告模版/` | 只读教师模板 |
| `绘图/`、`论文/`、`调研/`、`视频/`、`GOMAA-Geo/` | 图表、参考与既有第三方工程；原件按其角色保留 |
