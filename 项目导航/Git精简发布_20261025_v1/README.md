# GIT-005精简发布

本轮公开当前平台运行闭包、有效研究机制源码、关键报告/判定/协议和当前报告图表。旧平台独立发行目录、完整逐步数据、模型、第三方论文PDF、审阅过程、冷存储和备份只留本地；不把本机整个文件夹同步到GitHub。

三套旧平台的37份唯一验收材料已保字节移至本机平台/历史版本对应位置，当前平台根目录不再并列V2/V3/上传台。该历史目录不收录Git。辅助15000条旧队列回放用途不同，仍仅本地保留，不是当前发布平台。

当前唯一启动对为平台/启动平台.cmd与启动平台.ps1，版本4.13.1。旧编号的service/server模块有些是实际继承/导入依赖，会随当前平台保留；它们不是多个可选旧发行版。新克隆不含完整数据/权重，需按原SHA资产清单恢复；本轮不宣称干净机器全功能复跑。

本轮采用普通提交/推送，不重写既有提交、不强推。退出索引仅影响Git当前树，不删除本地科研原件。详细选择/排除清单和迁移SHA本地保存，公开摘要列出体积、检查和提交范围。
