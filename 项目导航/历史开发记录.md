## 必须遵守的规则

1. 源代码写入 `project/src/` 对应目录，不散放根目录；历史文档生成脚本先保留，不在未核查时迁移或删除。
2. 数据产出放入 `DATA/processed_data/<数据集>/`，不得修改原始数据。报告文件属于文档，放入 `选题报告相关/`。
3. **每新增文件夹，必须同步更新本 README 的目录用途说明**；自动生成的重复子目录可按上表路径模板登记。README 是工作区结构说明的维护入口。
4. **非代码目录优先中文命名**。既有 `DATA/raw_data`、`DATA/processed_data`、`models`、第三方和工具目录保留约定名称；代码目录使用英文小写。
5. 按2026-10-01用户提供的正式要求，本课题研究主动探索视觉地理定位与环境交互平台；允许训练小模型，多Agent为可选拓展。历史“零训练多智能体”是早期设想。GOMAA-Geo与GeoExplorer均包含训练；借鉴任务规则/训练机制不等于完整复现原模型，新增无训练协作层也不等于整个系统零训练。
6. 本地 Masa 为 137/4/10 张，论文所述 1188 张的差异来源尚未核实。不得称为已确认的“内部重切版”，不得把本地 SR 直接与论文数字相减证明提升。
7. 基础协议为四方向移动、越界原地且耗一步、预算内首次到达成功、最后一步到达优先判成功。无 `stop` 扩展动作。
8. Agent 只读取公开 Observation / StepInfo；禁止读取 episode 答案、目标路径索引、真实目标距离、全图、未访问网格/特征、评测日志。Python 对象私有字段不是恶意代码沙箱。
9. 开发在 train/val 进行。test 只用于冻结配置后的评测。跨 episode 记忆默认清空；持续学习/记忆共享属于独立实验协议。

## 当前交付与运行方式

已有 patch 和 Sat2Cap npy，npy 不是 VLM 主循环的必需输入，不进行模型训练。基础环境与评测仅依赖 Python 标准库和 Pillow（`project/requirements-foundation.txt`）；无需 torch / transformers 或 API 凭据。旧特征提取脚本另需其原有模型依赖。

在工作区根目录运行（生成器/评测器均使用相对于脚本定位的工作区路径）：

```bash
python -X utf8 project/src/data/make_episodes.py
python -X utf8 -m unittest discover -s project/src/tests -v
python -X utf8 project/src/eval/evaluate.py --splits val test --seeds 0 1 2 3 4
```

- 新清单每图×距离 4–8×5 次有放回采样（本地协议，不是论文原始 episode）。5×5 的距离8仅4种有序对，重复采样允许并记录。
- 支持固定5×5已处理数据；不能只改 `--grid-size` 就声称支持10×10或更大地理范围。
- 新输出若同名同内容则无操作；不同内容拒绝覆盖。变更协议/种子应另选新输出目录，并登记本 README。
- 评测产出只证明基础平台行为，不是 VLM 效果结论。环境/evaluator代码哈希在结果中作为审计记录，不是任务manifest门禁；修改执行代码后必须重新测试并另存新结果版本。
- 原始 `选题报告相关/build_report.js` 含旧版事实表述，不得用它覆盖校正版；本轮校正脚本在 `project/src/documents/`。
