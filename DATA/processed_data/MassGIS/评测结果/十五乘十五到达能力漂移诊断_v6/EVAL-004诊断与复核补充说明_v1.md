# EVAL-004 15×15到达能力与输入表征漂移补充说明

状态：只读诊断及另实现复核完成。EVAL-004本身不构成EVAL-002新域验收，也不改变S2/S3/S4、MassGIS默认方案、模型、均值、阈值或历史判定。

## 范围与数据

只读取[EVAL-002正式双网格报告](../正式十乘十十五乘十五确认_v1/正式双网格确认报告.md)封存的10个MassGIS区域、任务清单、数据清单、缓存特征与轨迹。每格300米、B20；10×10为750个任务，15×15为750个共同物理任务加250个更远任务。统计包含三个冻结权重和M0/Coverage3Radial。正式10区已经消费；本轮没有消费3个备用区。

根据原始bounds，10×10窗口`[46500, 879500, 49500, 882500]`位于15×15窗口`[45000, 878000, 49500, 882500]`的右上区域。逐格映射是**行索引不变、列索引加5**，每个区域有100个重叠物理格；对应PNG/特征相同。旧摘要中“同一物理端点的两个网格索引直接相同”不成立。例如首个配对起点由10格索引17映射到15格索引27。物理地点相同，网格局部坐标不同。

## 到达结果：扩区后全距离层都下降

| 队列/策略 | 10×10成功/计划 | 15×15成功/计划 | SR变化 |
|---|---:|---:|---:|
| 全队列 M0 | 1151/2250 = 51.16% | 575/3000 = 19.17% | 不能直接配对比较，15格多250道远题 |
| 全队列 Coverage3Radial | 1229/2250 = 54.62% | 608/3000 = 20.27% | 不能直接配对比较，15格多250道远题 |
| 750道共同物理题 M0 | 1151/2250 = 51.16% | 478/2250 = 21.24% | −29.91个百分点 |
| 750道共同物理题 Coverage3Radial | 1229/2250 = 54.62% | 504/2250 = 22.40% | −32.22个百分点 |
| 15格新增250道远题 Coverage3Radial | — | 104/750 = 13.87% | 单独列示 |

按10个完整区域作配对bootstrap（4000次，种子7317），共同题的15格减10格平均SR差：M0为−29.91点，95%区间[−34.53, −25.47]；Coverage3Radial为−32.22点，95%区间[−36.93, −27.51]。两策略均是10/10区域下降。Coverage的区域差范围为−45.78至−18.67点；M0为−46.22至−19.56点。

共同题按距离层的SR也全线下降：

| 距离层 | M0 10×10 → 15×15 | Coverage3Radial 10×10 → 15×15 |
|---|---:|---:|
| 短 | 36.80% → 24.80% | 38.93% → 26.13% |
| 中 | 50.93% → 21.87% | 57.33% → 22.80% |
| 长 | 65.73% → 17.07% | 67.60% → 18.27% |

因此，15×15低SR不只是新增远距离任务造成；共同物理任务上，每个距离层和每个区域都下降。三权重、重复题和双网格不是独立地理样本，地理样本数仍为10。

## 首步配对：坐标和访问桶改变了策略输入

核心配对为750道共同题×3个种子×2种策略，共4500条首步记录。日志中没有独立的`em`字段；首步公开位置对应同一物理格，首步visited只含起点、剩余预算均为20，当前图与目标图的保存特征哈希逐题一致。对188246条执行决策输入的重建哈希全部匹配。因而首步可观测差异来自输入中的归一化位置与25个访问桶布局，而不是图像向量、目标向量或首步预算差异。

由bounds映射推导的首步坐标变化为：`Δrow = r/14 − r/9 = −5r/126`，`Δcol = (c+5)/14 − c/9 = (45−5c)/126`。750个独立物理任务的平均变化分别为−0.1822和+0.1744；89.60%的起点在两种网格下落入不同的5×5访问桶。桶在训练5×5时对应单格；10×10评测每桶覆盖2×2格，15×15每桶覆盖3×3格。

首步动作提议有21.29%不一致。以真实目标仅作事后诊断，朝目标动作比例从10格1585/2250（70.44%）降到15格1445/2250（64.22%）；配对方向质量为15格更好83、更差223、持平1944（每个策略各2250条）。10个区域的首步平均方向评分均下降。逐动作logit差与坐标差的相关包括：up-logit/row `r=+0.442`，right-logit/row `r=−0.469`，down-logit/row `r=−0.619`，left-logit/column `r=+0.584`。这些记录由任务、策略和权重重复；相关和配对行数不能当成独立地图样本或因果检验。

## 完整轨迹与训练输入分布

4500条共同任务轨迹中4173条随后分叉、327条全程相同；分叉位置中位数为第4个位置。分叉前提议朝目标比例为10格18023/25719（70.07%）、15格16962/25719（65.93%）；分叉后为10格34622/50103（69.10%）、15格28707/56953（50.40%）。分叉后的状态已不同，这组比例是轨迹描述，不是隔离的首步因果效应。

从绑定的Small256_NoTarget训练轨迹重建491520个28维位置/预算/访问上下文，含41919个唯一上下文。25桶中平均饱和桶数（访问计数达到上限）为：训练0.021、10格0.790、15格2.290；平均占用桶数分别为4.63、4.87、3.81。评测状态到训练状态库的精确最近欧氏距离均值为10格0.559、15格0.610。结果显示较大网格输入的访问桶语义明显偏移，位置/预算上下文也与训练分布有差异。

另按缓存的512维当前图特征与109个训练源特征比较最近余弦距离，10格均值0.4923，15格0.4886；15格没有更远。目标通道是相同的冻结均值向量。因此现有证据支持**坐标归一化和访问桶布局漂移是合理贡献因素**，但不支持“15格图像特征距离恶化”这一解释。

## 结论、限制与唯一后续候选

到达率、首步方向、坐标/logit关联、访问桶饱和和训练状态近邻距离共同支持输入表征漂移参与15×15退化；它是观察性机制证据，**不能证明是唯一或充分原因**。区域扩大、轨迹分叉及预算/训练时域差异仍可能贡献。15格SR仍未通过EVAL-002的原验收门槛，本诊断不改变该结论。

这与前序证据相容：EVAL-003发现失败轨迹没有预算内可行动目标邻接机会；DEV-001把cue阈值提高到0.95后显著减少错误接受，但15×15仅增加1或2个成功题，其它网格SR下降，因此该阈值因素已收束。EVAL-004转向检查探索器到达及其输入是否随网格改变；不复活DEV-001候选。

只保留一个未执行的开发候选：[单因素方案草案](下一项单因素方案草案.md)：单独将位置编码改为`floor(5*row/k)/4`与`floor(5*col/k)/4`，对齐训练5×5格点；其余输入、权重、动作、阈值、策略和B20不变。候选需另立DEV批次，在已消费的`img_6100` 15×15开发题上先冻结源码/任务/门槛；SR提升至少2点、3权重中至少2个正向、SG不变差、分层SR损失不超过2点且审计通过，才可申请之后的独立确认。本轮未运行该实验，也未升级默认。
