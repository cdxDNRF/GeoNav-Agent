# DATA-002：真实15×15原生影像与任务准备

本批只做完整影像质量、原生拼图和任务工程；不加载神经策略、不训练、不执行导航动作，无新SR。资源和方法见[执行协议](执行协议.md)，输入/源码/模型保护见[预登记](核验/预登记.json)。

## 顺序接手

先读根AGENTS、TASKS、HANDOFF并认领具体范围；不得停止未知Agent进程。当前批次采用独占执行锁，旧进程仍执行时另一次运行会失败。中断尝试仍保守计入下载预算，不能删日志、重置次数、重复建同名输出。

用现有Python在仓库根按阶段调用`project/src/data/real_area15.py`：

1. `prepare`已经完成，禁止重跑创建目录；先核验注册和源码SHA。
2. `acquire`：从逐源核验记录恢复；若`元数据/全部源核验.json`已存在直接进入下一步，不重跑本阶段。
3. `select`：核对全部源及固定质量、重复/地理规则，选择2已知工程区及质量合格的10新区；`元数据/区域选择.json`已存在时先读取，不覆盖。
4. `build`：原生4500拼图/225图块/来源/任务，公开环境reset不执行动作；已有工程数据输出时先核对落盘状态，不覆盖重建。异常中断后另立恢复适配版本并保留已写原件。
5. `project/src/eval/audit_real_area15.py`：另方程完整数据复核；输出存在时读取，不覆盖。数据准备是否通过以最终判定及复核为准。
