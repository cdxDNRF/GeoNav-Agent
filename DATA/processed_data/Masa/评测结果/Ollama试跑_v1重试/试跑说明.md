# Ollama gemma4:31b 最小VLM试跑

## 结论

用户指定的 `https://ollama.com/v1`、`gemma4:31b` 已完成OpenAI-compatible双图动作调用。接口可用，实测完整请求平均2.81秒，适合第一版离线实验；不能仅凭这次小样本断言模型具有可靠定位能力。

统一评测/日志与最小单VLM已接入，尚无多智能体、研究记忆或层级搜索。所有原始记录保留，未跑完整test。

## 调用范围与失败记录

- 首次模型列表查询HTTP200且包含用户指定模型。
- 第一个试跑目录 `Ollama试跑_v1` 的再次模型探测遇到ConnectError；未发图像推理，VLM任务标记not_run。
- 本目录保留一次显式重试：固定选择val距离4、6各一道题，共2题，每题预算10步，最多20次动作请求。
- 实际发送16次双图推理；前15次得到合法JSON动作，第16次返回完整Markdown围栏包裹的JSON，被原严格解析器拒绝，随即停止。无自动重试、无随机动作回退。

每步双图：目标图和当前图；文本状态包含当前位置、预算、visited及四方向动作列表。没有真实目标位置、真实距离、原始图片文件名、未访问图片或历史对话。图像能被接口接受不等于已证明模型真正利用视觉；本次未做无图/错图消融。

## 格式兼容补丁

第16个响应为：

````text
```json
{"action": "left"}
```
````

已补充安全兼容处理：只允许剥离包住整个JSON的完整代码围栏，然后严格校验仅有action字段、动作在四方向内、无重复JSON键；不提取任意正文中的动作、不修正非法动作、不接受stop或截断回答。

对保留的16个响应做了**离线解析回放**，16/16通过，其中1个围栏被剥离。回放没有发送API、没有执行后续动作、没有重算原试跑SR；原有失败记录不改写。补丁的真实连续在线表现尚未再测。当前parser代码hash与原试跑代码hash不同，分别记录在离线回放文件和原运行配置中。
