# 主动视觉地理定位：分阶段验收标准 v1

制定日期：2026-09-29。适用范围：当前零训练、局部观测、四方向移动项目。本文规定后续实验的放行标准，不修改历史结果、不启动新一轮模型调用。

## 1. 先明确“能用”指什么

1. **数据/日志能分析**：协议正确、无答案泄漏、样本和失败记录完整，即使 SR 很低也能作为负结果使用。
2. **方法值得继续验证**：小规模验证出现足够信号，可以投入更多同尺度验证；不代表方法已有效。
3. **方法允许扩大实验**：经过完整验证、消融和独立源图复核，效果及成本达到门槛，才进入大网格/跨数据集实验。

完成率是工程质量；SR 是定位效果。19/20 题运行结束不等于19题定位成功。所有放行必须同时通过数据质量与效果门槛。

以下数值是本项目的工程/研究决策阈值，**不是论文规定的合格线，也不是统计显著性的替代物**。本标准制定时已经看过20题结果，因此对旧结果的评级是回顾性评级；后续批次须先冻结标准再运行，不能运行后降低阈值使方法过关。

## 3. 数据质量与指标口径

### 3.1 原始数据与任务清单

- 每个 search area 的所有图块必须来自同一合法源图；图块解码、数量、尺寸、网格编号及元数据映射均通过校验。
- 同一源图的图块不得跨 train/val/test；如能获取地理坐标，应把空间重叠/相邻且强相关源图作为同组隔离。源图不同不自动证明地理独立。
- 固定 grid、B、C 档位、目标模态、动作/边界/终止规则、采样种子、任务和图块哈希。合法起终点、距离一致且满足 C≤B；不可达任务只可另列压力测试。
- 记录有放回抽样和重复题。当前 val100 中只有 **86** 个不同 `(area,start,goal)` 组合，来自 **4** 张源图；重复3轮不是300个独立任务，更不是300张地图。
- Agent 只能读目标像素、当前局部像素和公开状态；不读任务答案、目标文件名/坐标、真实距离、全图、未访问特征、评测端日志。每题重置记忆。

### 3.2 每轮必须报告

本项目的**主放行指标只有一个：`SR_gate`**。它等于成功题数除以计划题数；API 中断、解析失败或没有终态的题都不能计作成功。`SG_gate` 是与主指标并列的第二个硬门槛，用来约束“没有成功但已经接近目标”的情况；`Q` 只负责判定评测工程是否完整，不能替代 `SR_gate`。因此，任何阶段都不能用“完成 19/20 题”代替定位成功率。

| 指标 | 定义与用途 |
|---|---|
| 完成率 Q | 正常到达目标或耗尽预算的题数 / 计划题数。到预算结束也算运行完成，不能算定位成功 |
| SR_nav | 成功题数 / 正常完成题数；与 SG 一起描述导航能力，必须同时列分母及 API 中断数 |
| SR_gate | 成功题数 / **计划题数**；用于放行的保守交付成功率。中断题记“未证明成功”，错误类别仍单列，不能伪装成预算耗尽 |
| SG_nav | 所有正常完成题的终点到目标曼哈顿距离均值，成功题距离为0；不能只统计成功题或只统计失败题 |
| SG_gate | 中断/未运行题按该网格最大距离 `2(K−1)` 补入的保守均值，仅用于放行；它是上界约定，不能冒充实际终点距离。Q=100%时等于SG_nav |
| 距离宏平均 | 先对每个 C 档计算指标，再对预先规定的档位等权平均，最后对全部重复轮次等权平均；不挑最好一轮。缺一档则不放行 |
| 重复访问率 R | 重复访问动作数 / 总执行动作数，撞墙原地也算重复；同时保存每题率 |
| 邻域诊断 | “曾到距离1但未成功”的题数、进入邻域题数及条件比例；原始题数下降可能只是更少接近目标，不可独立当作提升 |
| 成本 | API尝试/错误、每题请求数、输入/输出token、端到端时延P50/P95；usage缺失记缺失，价格未知不编造费用 |

论文 SR/SG 只在无缺失任务且协议对齐时与本地 SR_nav/SG_nav具有相应含义。后续门槛表中的 SR、SG，除另注明外，指上述按距离宏平均的 **SR_gate、SG_gate**。

常规正式批次 Q≥99%，全部计划任务均有终态记录，所有已记录轨迹可重放；20题试跑要求20/20。不因 API 失败换题、不只保留成功重试。请求重试规则提前锁定（当前瞬态错误至多重试一次），失败批次永久保留；如整轮重跑，应先声明规则并另建目录，不能挑最高分版本。

所有策略共享环境、清单、预算与信息边界。调提示词、调阈值、改变治理器、增加图像或改变预算都形成新配置。保存可恢复的代码版本/源码快照及模型、完整提示、解码参数、哈希；仅有哈希不足以恢复历史源码。

## 4. 阶段门槛与允许推进的工作

同一行条件必须全部满足。失败时可以继续做原因分析、模块修复和负结果报告；不能把“进入下一实验”写成“本方法已通过验收”。

| 阶段 | 样本与重复 | 硬门槛 | 通过后允许推进 |
|---|---|---|---|
| S0：数据和评测可信 | 单元/边界测试、数据清单检查、逐题重放 | 无答案泄漏；任务/图像/代码可核对；计划题记录完整；指标可由日志重算；测试通过。**不设SR下限** | 做策略实验；低SR数据仍可作负结果 |
| S1：小规模候选 | 固定 validation20-v1，20题，1轮 | Q=100%；**SR≥40%，SG≤2.5，R≤10%**；SR比同题Random至少高10个百分点 | 扩到完整val100；不允许据此宣称方法有效或直接启动大规模跨域实验 |
| S2：5×5稳定且机制有证据 | 固定val100，**3轮**；5×5、B=10、C=4…8；G/E/对照相同任务 | 每轮Q≥99%；**平均SR≥60%，平均SG≤1.8**；比同题最强预登记无图规则的SR至少高 **5个百分点**，SG不高于该规则；每个C档平均SR≥30%，其中C=7、8各≥40%；每轮R≤10%；三轮SR极差≤10个百分点，至少2轮优于规则；另满足下文消融要求 | 冻结方法，做独立源图复核及小规模扩展准备 |
| S3：独立源图复核 | 冻结后本地test250、10张源图，3轮；不再调参 | 每轮Q≥99%；**平均SR≥55%，平均SG≤2.0**；相对同题最强规则SR至少高5个百分点，SG不更差；至少6/10张源图的平均SR有正增益；每轮R≤10%；完整报告分组置信区间 | 开始10×10正式实验，再逐个跨数据集验证；仍不以这10张源图推断全球泛化 |
| S4：扩展验证 | 每种扩展单独固定任务/预算/对照，按下表验收 | 效果、质量与成本共同达标；不得把不同设置合并成一个过关分数 | 完成相应扩展；10×10通过后才考虑25×25 |

S1 是筛选信号，40%不是合格产品水平；S2 的60%接近两篇论文标准设置的参考量级，且高于当前完整val100的Frontier 53%。SG=1.8比本地规则2.11更严格。+5个百分点用于要求额外复杂度产生有实际意义的收益；这些是管理阈值，不代表统计检验自动显著。

### 4.1 S2 的必要对照与消融

- **E、G、Frontier、Random**：同题同预算；Random固定种子0、1、2。确定性的规则只需执行一次并核验可复现，不把复制的分数当随机重复。
- **固定区域排序的无图规则**：固定行优先粗区域顺序及 `up,right,down,left` 动作顺序，使用相同 G 治理逻辑。它与Frontier一起组成预登记规则集合。不得遍历大量顺序再用最高分冒充预登记基线。
- **G去区域治理**：使用与G相同的层级提示、两张图和返回字段，但在线执行时忽略 `ranked_regions`，改用 E 的动作治理。用于分离提示变化和区域治理的作用。
- **G目标遮蔽**：目标图换为预先固定的中性灰图，保持两图格式、其余提示与治理逻辑相同；遮蔽整题不变。环境仍用原来的真实目标判定成功。仅在评测端保留这一映射。
- G 相比“去区域治理”和“目标遮蔽”分别要求平均SR至少高 **5个百分点**，且各至少2/3轮为正增益，SG不更差；否则不能认定层级治理或目标视觉信息贡献成立，也不进入扩展阶段。
- 消融必须在线跑各自轨迹。动作一旦分叉，旧日志中的后续图片/模型响应不能用于拼接新策略的SR。

以上因素是受控组件比较；G与E的直接差值同时包含提示/schema与治理变化，不能单独归因于层级规划。F留作负结果，不并入G。

### 4.2 S3 的统计与test使用边界

- 先按源图（有空间重叠时按地理组）配对聚合，再做2000次成组bootstrap，报告SR差和SG差的95%区间。不得将重复路线/轮次当作独立地图；4张val源图的区间只能作开发诊断。
- S3放行是项目资源决策。如果SR差的95%区间下界仍≤0，即使点估计过关，也只能写“观察到增益、证据有限”；要写稳定优于基线，应增加独立地图且区间支持正增益。
- 目前10张test源图只支持有限的本地留出验证。前期已做Random基础验收，不能称这些数据从未被任何流程读取；尚未作为VLM调参集使用。
- test评测前锁定全部配置与3轮计划。看过test后不能反复调到过线；若失败，记录失败，回开发集研究，下一版结论需新的未用于开发的留出地图。
- 本轮只制定标准并核算val规则基线，未运行test模型实验。

## 5. S4 扩展指标

下面的SR/SG仍采用第3节的放行口径。每项至少20个源图区域、每个C档每区域5个任务、3轮；记录重复组合和区域相关性。若数据只有15个区域，可先做探索报告，但不宣称达到这里的规模门槛。每项要求每轮Q≥99%，SR超过该设置下预登记最强无图规则至少5个百分点，SG不更差。

| 扩展分支 | 固定设置 | 最低效果门槛 | 后续动作 |
|---|---|---|---|
| 首选：10×10紧预算 | B=20，C=12…16；≥500任务/轮 | **SR≥30%**；**归一化SG≤0.25**，即SG≤4.5 | 通过后做跨域或25×25；25.19%论文值仅启发量级，仍以本地规则差为准 |
| 可选：10×10较宽预算 | B=32，C=14…18；≥500任务/轮 | **SR≥60%，SG≤2.0** | 独立报告；该分支通过不能替代B=20分支过关 |
| 跨数据集先保持5×5/A | B=10，C=4…8；每数据集≥500任务/轮 | **SR≥45%，SG≤2.5**；另报相对源域的变化 | 每个数据集独立验收；换地面图/文本另开模态实验 |
| 后续25×25 | B=60，C=12,16,…,48；≥1000任务/轮 | **SR≥20%，归一化SG≤0.30**，即SG≤14.4 | 完成高难度扩展，保留失败距离档分析 |

归一化SG=`SG/[2(K−1)]`，只能缓解网格距离量纲变化，不代表不同地理范围/分辨率已可比。R在大网格先作诊断，不把“任何回退都坏”设为硬约束，必要回退可能提高SR。

扩展必须事先声明：是把同一1500×1500源图切得更细，还是维持单格地理视野并扩大搜索范围。前者是分辨率/网格密度压力测试，不能写成覆盖了更大的真实地理区域；后者需要更大源图或有地理依据的连续拼接，不拼无关图片。B=20和B=32不能混算，也不允许更大预算结果替代较小预算的失败。

每种新尺度先做20题工程试跑再进入正式批次；跨域/新尺度可以暴露失败并形成有效研究结果，但不自动放行更多扩展。

## 6. 成本与停止规则

- 每批运行前冻结API请求上限、模型和提示版本。当前单VLM决策每步一次请求、瞬态错误最多重试一次，N题预算B的硬上限为2NB次尝试；禁止无限重试或超预算找高分。
- 当前阶段效率参考：每题平均有效决策请求≤B、请求时延P95≤15秒；报告每题tokens和总tokens。缺失usage必须标明，不能记0；费用未知可不填人民币金额，不影响算法指标计算。
- 若未来引入多Agent，其API成本属于新因素，须先登记新的调用上限，再和单Agent比较成功率/请求数，而非沿用“一步一次”假设。
- 格式/调用失败导致Q<99%：先修工程问题。Q达标而SR/SG未达标：修策略或证据使用；不能以完成率替代定位效果。
- S2/S3未通过：不扩大网格/数据集、不把F叠回G、不继续堆模块；先检查目标图消融、固定规则、失败轨迹和长距离档。
- 标准需要变更时写v2并注明原因；仅用于之后尚未运行的批次，历史v1结果保持原判定。
