# 首次目标邻接时机：配对补充

本表使用同题、同权重且两方法都曾在有预算时进入目标相邻格的记录，避免仅比较不同“已到达”样本集合。负差表示新方法更早到达邻接状态；它表示视觉检验机会，不代表视觉头已经正确接受目标方向。

| 对照 | 两者均有邻接机会 | 更早 / 相同 / 更晚 | 平均首次邻接步数差 |
|---|---:|---:|---:|
| 5×5继续训练对M0 | 1023 | 167 / 560 / 296 | +0.42步 |
| 10×10适配对M0 | 1023 | 300 / 572 / 151 | −0.45步 |
| 10×10适配对继续训练 | 1059 | 335 / 595 / 129 | −0.69步 |

以全部1500计划记录计算20步内的截断平均等待时间，未在预算内邻接者右删失于20（不是伪造的到达时刻），差值分别为+0.015、−0.491、−0.506步。定义与完整计数见[配对数据](邻接时机配对补充.json)。本项事后诊断不修改冻结候选条件。

10×10训练适配提供了更早接近目标的信号，但相对继续训练SR只+0.27个百分点，SG反而增加0.235格，未通过升级条件。不能从“更早进入邻接格”跳到“可靠目标识别”或“整体导航更好”。Continue5相对M0取得更高SR点估计与更小SG，却没有在共同到达记录上更早邻接；其作用也不能概括为所有题都更早获取线索。

这些比较仍限于20已见源文件、同500题×三权重，不等于新增独立地图确认。[主报告](探索器协议适配报告.md) / [原始时机记录](邻接时机诊断.json) / [独立复核](独立复核.json)。
