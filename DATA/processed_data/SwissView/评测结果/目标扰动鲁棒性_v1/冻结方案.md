# 目标扰动鲁棒性配对验证 v1

制定于2026-10-01，所有扰动结果读取前冻结。用户授权继续界定边缘线索适用范围。采用已完成的SwissView100正式20图/500题/C4…8/B10及三个Masa训练权重；这是已见源图上的受控压力测试，不是新的独立地域确认，不消耗剩余76张未运行源图。

## 数据身份与规模

Masa为[Massachusetts Buildings航拍数据](https://www.cs.toronto.edu/~vmnih/data/)，本地原图train137/val4/test10。当前探索器拟合原train中的109图，边缘头在其中87拟合、22校准；其余28为开发留出。本地151图口径不同于论文自行划分/任务清单，不能把本项目分数当论文复现。

新域来自[SwissView作者数据卡](https://huggingface.co/datasets/EPFL-ECEO/SwissView)，其SwissView100为100张瑞士航拍图。本地100张完整原图，之前试跑用了00…03四图，正式用了20…39二十图，共24图；正式500题中424不同路线、76次重复抽样，每份权重跑同一试卷。20个源文件簇是地理推断的样本单位，1500次执行不是1500张地图。当前属于按项目协议完成的正式规模验证，地理覆盖仍有限。本轮沿用这20图作配对扰动；Monuments地面图、MM-GAG、跨视角、异时影像均不在本批。

## 预先固定的七个条件

都从原300×300 JPEG图块**解码RGB**开始，只改变给定目标图，当前观察/真目标位置/任务/预算/环境终止均原样。每项单独应用，无组合、强度搜索或根据成绩选扰动；结果保存无损PNG，除指定JPEG操作外不增加二次有损编码。

| 代号 | 唯一操作 | 检查的问题 |
|---|---|---|
| Clean | RGB原样，无损PNG | 当前通路完整复现父批 |
| Bright080 | 每RGB值乘0.8、向下取整为uint8 | 曝光差导致的边缘颜色变化 |
| JPEG25 | Pillow JPEG quality25，明确subsampling=2后解码RGB | 压缩损伤 |
| Blur1 | Pillow GaussianBlur radius1.0 | 细节/边缘高频损失 |
| Crop8 | 四侧裁8像素，284×284再BICUBIC放大300 | 给定目标视野与尺度稍变 |
| Rot90CW | 精确顺时针旋转90度（transpose），无插值 | 方向一致先验破坏 |
| Ring8 | 最外8像素RGB全部填128，284内区像素不变 | 图块边缘可用性破坏 |

旋转后的图仍指同一位置，Agent不获取旋转角度，也不做反旋转；它是已知方向一致策略的压力测试，不是改变地图坐标或声称已具旋转不变性。Crop/Ring会同时改变重算的语义与边缘输入，不能把差值单独归因于某一个通道。没有真实异时影像，不用合成扰动冒充跨季节/异时证明。

## 冻结策略与计算

原Small256 NoTarget探索器、EdgeTargetCue头、四份Masa均值、阈值0.50、合法动作筛选、raw五类概率最高候选合法且未访问才介入、argmax/每题重置全部原样。不训练、不调参、不做模型集成，不读源ID/真目标位置/距离/未访问特征。

每个条件完整在线执行Full和NoTarget/Baseline，500题×3×7×2=21000神经轨迹。NoTarget的探索输入不读目标，应逐条件复现父批NoTarget动作；虽然动作理论不变，仍在线记录每个条件，不以拼接日志代替。Full一旦分叉不能复用父批后续观察。Clean Full全部1500轨迹应复现父批真实目标；基线每条件全部复现同题父批动作，否则先解决工程问题。

目标PNG及其全局/局部/profile全部从修改后的RGB重算，不能只替换图像却使用原特征。当前图的父批已审计特征原样使用；独立审计重新提取当前500图和3500个目标变体特征与像素。编码器CUDA，策略CPU FP32，单线程确定性，CUBLAS设定原样。profile包装器只接收给定两图对应数组。父批两种规则不依赖目标，逐条核验父批记录后按哈希复用；不把规则复制成七次独立测量。没有API请求、模型下载或安装。

## 判定与统计（不是新阶段认证）

每条件先报告SR/SG/Q/R/种子极差/C档/源图/实际接受线索精度及失败相邻机会。质量必须完整终态、合法动作和全量复核。父批正式验收保持原样，不因某扰动失败撤销既有干净设置结论。

每扰动独立报告两项新诊断判定：

- **性能保持**：相对本批Clean的平均SR下降≤5个百分点，平均SG增加≤0.30格。
- **目标收益保持**：同条件Full比NoTarget平均SR≥+5点、至少2/3种子正增益、SG不更差；SR源文件95%区间下界>0另列证据。

两项都是本批运行前规定的工程解释尺度，非论文规定的合格线。单个固定强度通过不能证明一整段扰动范围都通过；破坏性条件允许失败并形成适用边界，完成压力测试不等于“全条件鲁棒”。额外列原跨域工程门槛SR≥45%、SG≤2.5、对最强原规则≥+5点/SG不更差，但不让高NoTarget能力代替视觉目标贡献。

每源文件先配对平均三权重、seed3031/2000次成组bootstrap：各条件Full−NoTarget与Full−Clean的SR/SG区间。六个非Clean条件的Full−NoTarget SR另给Bonferroni式尾分位区间，尾概率0.05/(2×6)，作为六项同时解释的保守敏感性参考；百分位bootstrap仍为有限20源文件近似，不是精确覆盖保证。普通95%区间不能称同时95%保证。所有条件/强度完整列出，不挑高分条件重新定义总体。
