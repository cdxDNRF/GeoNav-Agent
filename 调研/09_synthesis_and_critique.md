# 综合论证与红队审查

> 用途：供主报告整合的六领域研究综合与下一轮实验审查。仅综合 `01–06` 既有材料和 `DEEP_RESEARCH_active_image_goal_search.md`，本文件未进行外部检索。文中标为“论文事实”的内容是来源卡所记录的研究设定；标为“本项目推断”的建议须由本地配对实验验证。引文标签保留来源ID，便于主报告映射。

## 一、六个研究领域的报告正文

### 1. 主动地理定位：局部观测与隐式历史策略

**论文事实。** AiRLoc、GOMAA-Geo 与 GeoExplorer 是任务结构最接近的工作：环境持有完整航片和目标坐标，策略按步只接收当前位置的局部航片、目标线索和动作历史，在四邻网格内搜索。GOMAA-Geo 以跨模态对齐、历史序列建模与 PPO 选择一步动作；GeoExplorer 另训练动作条件的下一观测特征预测器，将预测误差作为好奇心奖励；DynCur-Geo 的新意集中于训练阶段对好奇心权重作目标距离门控并加入 PBRS。它们都没有因此变成显式图搜索器，也不应被统称为免训练方案。[G04](https://arxiv.org/abs/2209.03694) [G01](https://arxiv.org/abs/2406.01917) [G02](https://arxiv.org/abs/2508.00152) [G03](https://arxiv.org/abs/2608.18673)

**本项目推断。** 可复用的是“目标图、当前观测、已访问历史共同影响下一步”的接口，不能直接复用论文的奖励收益。本地已做 BC、PBRS、动作条件好奇心、目标遮蔽与局部匹配，不能重列为新模块。文献数值不能和本地结果排行：数据、预算和停止协议不同。核心问题应是目标视觉证据何时能改变覆盖策略，并在独立地点提高预算内命中。

### 2. 图像目标、实例目标与类别目标

**论文事实。** InstanceImageNav 的目标是图像中指定的同一对象实例；ObjectNav 通常允许到达任意同类对象；图像地点导航则可能要求回到拍摄地点。模块化图像目标方法把探索、实例重识别、候选位置估计和路径执行拆开，IEVE 又在目标候选状态间进行探索、验证和利用切换。这些工作支持“目标图应产生可追溯的匹配证据”，并展示了把感知与执行分模块评估的价值；但其室内物体、RGB-D、近距离验证和停止规则与整幅航拍图块定位不同。[N01](https://arxiv.org/abs/2211.15876) [N02](https://openaccess.thecvf.com/content/ICCV2023/html/Krantz_Navigating_to_Objects_Specified_by_Images_ICCV_2023_paper.html) [N03](https://openaccess.thecvf.com/content/CVPR2024/html/Lei_Instance-aware_Exploration-Verification-Exploitation_for_Instance_ImageGoal_Navigation_CVPR_2024_paper.html)

**本项目推断。** 任务宜定义为“给定目标航片，在局部观测网格中寻找对应地点”。评估需区分精确同源图块、同地点异视角、同类地物异地点；后者只能作匹配难例。若目标和地图来自连续航片切片，边缘连续性可能有效，但只支持该采样协议，不能自动外推到跨时相、高度或旋转视角。错误目标应保持相似地物难度，避免容易负例夸大目标贡献。

### 3. 层级控制、waypoint 与预算内路径规划

**论文事实。** 层级导航已有不同接口：HRNav 使用高层短期子任务与低层策略；SPF 让冻结 VLM 指定图像中的 waypoint，再由控制器执行；SemNav 在候选 frontiers 上做长程规划，Gao 等人的四旋翼预印本则联合候选视点、记忆图和轨迹执行。SPF 的同论文动作接口消融支持检验 waypoint 输出，但并未证明它一定胜过四方向网格动作；SemNav 的 greedy/LSP 对照支持独立检验路径规划，但其目标为 ObjectNav，且完整系统依赖预训练低层策略。[G06](https://aclanthology.org/2026.acl-long.1352/) [N08](https://proceedings.mlr.press/v305/hu25e.html) [N07](https://arxiv.org/abs/2506.03516) [N09](https://arxiv.org/abs/2606.29917)

**本项目推断。** 单步打分每步重选方向；receding-horizon 规划一段候选动作、只执行首步、收到真实观察后重算；持久 option 则暂时承诺 waypoint，并按到达、反证、强线索或超时中断。budgeted coverage 优化预算内新格访问或漏访率，不等于目标条件规划。它们可共用 BFS 代价，仍须分臂比较。goal-aware planner 超过同预算 coverage-only 才支持目标证据的规划收益；否则只支持覆盖规划。

### 4. 视觉记忆与跨步证据

**论文事实。** TSGM 在已观察视点与对象间建立拓扑记忆；UniGoal 匹配目标图与在线场景图并随证据完整度切换搜索阶段；MemoNav/Memoir 筛选或检索历史；FTM 表征未访问 frontier。这些工作支持记忆保留目标相关关系与失败经验，而非仅记录访问状态。原方法依赖室内连续观测、对象检测或训练组件，不能把论文成绩当作 5×5 航拍网格的预期收益。[N04](https://proceedings.mlr.press/v205/kim23a.html) [N05](https://openaccess.thecvf.com/content/CVPR2025/html/Yin_UniGoal_Towards_Universal_Zero-shot_Goal-oriented_Navigation_CVPR_2025_paper.html) [S09](https://proceedings.mlr.press/v205/kim23a.html) [S16](https://arxiv.org/abs/2402.19161) [N21](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/08905.pdf)

**本项目推断。** 最小记忆应记录已观察位置、图像标识、目标关系、支持/反证、置信来源与 option 结果，并区分 `observed`、`model_inferred`、`unobserved`。重复观察静态图块不能算独立证据。项目已有邻接概率、方向解耦、边缘连续性和邻域确认；新问题只能是跨多个已观察节点融合目标关系与反证，且优于冻结 Edge、FIFO 历史和打乱位置对照。把邻接线索改存图节点只是换表示。

### 5. Belief、主动搜索与信息增益

**论文事实。** GPOMCP 等 POMDP/MCTS 工作依赖明示的状态、转移、观测似然和 belief 更新；MAX 的 ensemble disagreement 可作为探索 proxy，但其不确定性表示模型对动作后果的分歧，不是目标位置后验。已知地图上的 UAV 定位则利用地理配准参考图更新位置 belief，改变了本任务的信息前提。[S13](https://proceedings.neurips.cc/paper_files/paper/2023/hash/a6d7226db2ff3643d8624624e3859c19-Abstract-Conference.html) [S03](https://proceedings.mlr.press/v97/shyam19a.html) [G12](https://doi.org/10.1016/j.robot.2023.104497)

**本项目推断。** 自身格位、网格几何和动作转移已知，未知的是目标格与未观察图像；这是目标条件搜索，不是自身位姿未知的 SLAM。BFS/Manhattan 只算路线，不识别目标。相似度、VLM 自信、候选数或模型分歧不能叫 posterior/真正信息增益，除非先定义并校准先验与观测模型。若不同目标方向对应的未知地图在已访问位置完全相同，当前历史无法区分；没有道路、边界连续性或区域先验等可识别线索，就应覆盖搜索或弃权。

### 6. World model、无人机迁移与协同搜索

**论文事实。** Navigation World Models、BEINGS 与 NavWAM 预测或生成未来观测并用于规划，但依赖大规模动作—视频经验、仿真预训练，或可渲染的 3D Gaussian 场景先验。UAV 图像目标搜索的近期预印本结合跨图记忆、候选视点和轨迹规划，说明无人机任务可以使用分层空间状态；多机 active-search 研究则处理通信、区域分工和稀疏信号等不同目标。[S17](https://arxiv.org/abs/2412.03572) [S22](https://www.mwg.ink/BEINGS-web/) [S23](https://arxiv.org/abs/2606.13494) [N09](https://arxiv.org/abs/2606.29917) [S24](https://proceedings.mlr.press/v161/ghods21a.html)

**本项目推断。** 连续航片、配准卫星图或地理纹理模型可能给未访区域提供先验，但现有材料未证明本地网格有这种关系。独立抽样的隐藏图块无法从当前历史恢复真实像素；生成结果只能标为模型先验。5×5 确定转移下先检验目标线索、证据记忆和短路径规划；SLAM、世界模型和多机协同属于额外假设更强的后续课题。

## 二、对五项下一轮实验的红队审查

### 重复风险与可保留的新问题

- **E0 目标线索压力与冻结复验：部分重复，但适合作为协议审计。** 本地已有 Edge 连续性候选，且目标线索开发过程、邻接/方向头与局部匹配已有记录。重跑旧 val100×3 只能查复现稳定性，不能产生独立地图泛化证据；现有 val 来自 4 张源图且按距离有放回采样。颜色、裁剪、旋转、边缘遮挡的逐因素压力测试仍有诊断价值，但应称为“Edge 适用范围/敏感性分析”，不称新方法。没有新源图前，不能用该项宣称跨地区验证。
- **E1 持久 waypoint：有条件的新架构问题。** 既有 G 层级粗区域排序已做；若新臂仍是每步让 VLM 重排区域，则重复。只有明确保留 waypoint、逐步计动作、设置中断事件，并同每步重规划及无目标持久 waypoint 比较，才检验“承诺与重规划调度”本身。调用减少是控制效率结果；只有真实目标优于匹配错误目标和 NoTarget，才是视觉定位证据。
- **E2 结构化关系记忆：高重复风险。** 邻接线索、条件方向解耦、局部匹配、邻域确认和 Edge 线索都已做过。新颖部分只可能是跨步、多节点的支持与反证累计。应冻结 Edge 作强基线，使用等图像/token 的 FIFO、打乱位置、错误目标和类别摘要；如果只提升去重或 cycle avoidance，贡献是探索记忆，不是目标图理解。缺少独立源图时只可做机制开发。
- **E3 短路径 beam：可以做，但应定位为规划分解实验。** “规划几步、执行首步、读新图、再规划”就是 receding-horizon 方案的实现方式；它本身既非新颖，也不等于 information gain。把目标线索分数固定，比较单步贪心、持久 waypoint、goal-aware beam 和 coverage-only beam；分别显示覆盖规划效应与目标分数效应。未知格没有实际图像，不能计入观察到的目标分数；若没有似然/观测模型，分歧只能称 proxy，不能称期望信息增益。
- **E4 跨步关系 scorer：当前提最苛刻，建议后置。** 项目已有目标邻接/方向小头训练及校准失败，也有冻结动作动力学 curiosity；再训练 PPO、PBRS 或泛化 curiosity 会明显重复。E4 仅在不改 RL 奖励、不重训视觉编码器的前提下，学习“多个已观察节点的有来源关系与反证如何组合”，才与先前工作区分。先用冻结 Edge 检验开发候选线索是否能跨节点、跨源图稳定提供信息；若无此证据，不启动 scorer。

### 必须写清的评估边界

1. **4 张源图不等于 100 个独立地理样本。** 当前 val 的 100 题有放回取自 4 张源图，部分路线重复；episode 配对可估同一批图上的策略差异，但按源图聚类的区间只有 4 个簇，不能支撑稳定的跨地区总体推断。统计单位和结论范围应写成源图级别；小簇置信区间会很不稳定，不能靠 episode bootstrap 放大样本量。正式泛化需要真正未用于选择方案的源图/地区，来源不足时就明确结论是开发证据。
2. **已知 28 张开发图不能重新命名为独立确认集。** 它们已进入开发决策，即便某个新模型没有直接拟合它们，也不再是未被观察的最终测试集。后续应新增来源并先冻结方法；当前 test 不用于调阈值或挑方案。E0 的扰动评测依然可回答稳健性问题，但不能修复独立性。
3. **本地终止规则与真实无人机任务不同。** 环境在智能体进入目标格时自动成功终止、无 `STOP` 动作；因此验证或停步头在抵达后没有额外决策价值，不能把室内 InstanceImageNav 的目标确认收益直接移植为终止收益。若要研究真实无人机发现/确认/停止，需另建传感器检测、误报代价与显式 stop 的任务协议。
4. **“Task-free”要限定为任务奖励定义。** 在探索文献中它通常指探索奖励不依赖某个具体下游目标；不意味着不训练、不使用预训练模型、无数据、无环境假设或能零样本定位目标。报告应分别说明冻结预训练、目标任务监督、RL 交互、目标坐标 oracle 只用于训练奖励、推理时可见信息，避免把“task-agnostic intrinsic exploration”宣传成“完全免训练的目标搜索”。
5. **证据强度与方法新颖性。** 直接 AGL 论文的观测/训练设定与方法事实置信度高；InstanceImageNav 和层级接口的模块思想证据中高，但迁移到整幅航片的收益只是设计推断；belief/IG 与世界模型的原则边界证据中高，具体本地增益未知；本地 Edge 目前是开发候选，真实性能和统计区间可读档案但本轮未重算，跨采集泛化置信度低。把 edge、图记忆、beam、curiosity、VLM waypoint 同时拼装，只会形成难归因的模块堆叠，不能自动形成新颖贡献。

### 建议的主线与可审核心贡献

主线收窄为：**在已知几何、局部视觉可见、预算受限的网格搜索中，量化并利用目标航片提供的可追溯局部关系证据；研究何时保持覆盖搜索、何时把证据转化为持久可执行的子目标。** 核心主张应由“目标证据引起有益动作改变”来界定，而不是用了哪种 VLM、记忆图或 planner。建议先冻结并界定 Edge 线索和基线，再做 E1 的 option/重规划对照；E3 用同一冻结证据分数拆出 coverage-only 与 goal-aware 路径收益。E2 仅在确认跨步关系可识别后推进，E4 作为条件性后续。E0 中的旧集重跑属于复现核查，唯一能扩展外推范围的是预先留出的新源图。

最小可审因果链为：真实目标线索相对无目标和难度匹配错目标提高可接受线索覆盖；线索实际改写了一部分决策；在同一探索器、同动作预算、同调用上限下，目标引导决策提高预算内命中；该现象在冻结方法后的独立源图复现。若只有 NoTarget/coverage planner 改善，贡献应诚实定位于预算搜索；若只有 Edge 在同源切片成立，贡献应限定于连续图块边界线索。当前材料尚不能支持“通用跨视角无人机视觉地理定位”或“新型 belief-space/world-model 方法”这类更宽主张。
