# Phase-2 sources: instance image navigation, visual memory, and hierarchical planning

> Retrieval date: 2026-09-30 (Asia/Shanghai). Scope: primary research relevant to locating a target specified by an image while moving through an unknown grid, plus transferable embodied navigation, memory, VLM action interfaces, and aerial navigation. Evidence links were opened from primary conference/publisher/arXiv pages where available. Peer-reviewed publication and preprint dates are kept distinct. Source tiers: T1 = primary peer-reviewed paper or primary arXiv preprint; code/project links are recorded separately and are not treated as proof of peer review.

## Phase-2 synthesis for this project

The closest neighboring task family is instance-specific ImageGoal Navigation (InstanceImageNav): an agent receives a query image and must find the same object instance under viewpoint change. The user’s grid task is still different: the query may depict a whole aerial/satellite patch, while the environment exposes discrete map patches; success is a cell match, rather than approaching a 3-D object in an indoor scene. This distinction matters: class-level semantic priors such as “a bed is likely in a bedroom” should not replace query-to-observation visual correspondence when the goal is an exact image or exact map tile. [N01–N03, N06]

The literature offers a concrete upgrade beyond a visited bitmap and one-shot region ranking: store target-conditioned evidence on cell or graph nodes, including query-image similarity, supporting local features/landmarks, confidence and recency; connect these nodes by observed transitions; choose a persistent waypoint/option from the belief over candidate target cells; execute it with deterministic grid search; and replan after a short horizon or meaningful new evidence. Topological semantic memory (TSGM), online goal/scene graph matching (UniGoal), frontier search with a long-horizon planner (SemNav), and candidate-viewpoint planning for quadrotors (Gao et al., 2026 preprint) support these design ingredients. They do not establish that every part should be a learned graph or that a VLM must be removed. [N04–N07, N09]

For VLM output granularity, evidence supports several viable interfaces. Direct action selection has been demonstrated, but even direct VLM policies constrain candidates using maps, obstacle estimates, and an action proposer. Higher-level destination selection with a separate low-level controller or policy is also established. A useful controlled ablation exists in aerial navigation: SPF compares direct text action generation, selection among PIVOT image-marked candidates, and image-space waypoint labeling on its own navigation tasks; waypoint labeling performs better in that setup. It is not an experiment on four-direction grid movement or image-goal map search, so it is evidence for testing a waypoint/option interface, not a universal theorem about direct control. [N07–N11]

For the current 5×5, ten-step budget, three ingredients are especially affordable: (1) persistent subgoal/options that survive several primitive moves; (2) exact-image evidence memory that updates a per-cell target belief instead of merely marking visited/unvisited; and (3) a small budgeted beam or receding-horizon planner that scores candidate options using image-match evidence, prior belief, route cost and information gain. Do not start with 3D Gaussian reconstruction, a pretrained foundation policy, or full PPO over a large state space. These papers assume substantially richer 3-D geometry, larger datasets or longer continuous trajectories than this environment provides. [N06, N09–N10]

## Full evidence cards (10)

### N01 — Instance-Specific Image Goal Navigation: Training Embodied Agents to Find Object Instances

- **Authors/status:** Jacob Krantz, Stefan Lee, Jitendra Malik, Dhruv Batra, Devendra Singh Chaplot. arXiv preprint, submitted 2022-11-29; no peer-reviewed venue asserted by the primary record. [arXiv](https://arxiv.org/abs/2211.15876).
- **Task/data:** Defines InstanceImageNav in Habitat using HM3D/HM3DSEM; six object categories. The task deliberately makes the query an image focused on one object instance, with goal-camera intrinsics/pose independent of the navigating agent. It is not ordinary ObjectNav: stopping at another bed is failure.
- **Observation/action:** Benchmark specification uses egocentric RGB-D, image goal, GPS+Compass pose; discrete forward/left/right/stop actions in Habitat. The goal is proximity plus visibility of the depicted instance, not the image-capture pose.
- **Architecture/training/memory/planning:** This is principally a task and benchmark paper, not a new agent architecture. It establishes that image-goal navigation requires both instance re-identification across viewpoints and active exploration. The paper reports weak generalization for an end-to-end trained baseline, illustrating that an image-goal input does not by itself solve exploration or identity matching.
- **Transfer:** Use its “same instance, not same category” success definition if the project’s target is an exact patch. Recast a grid cell as the candidate instance/location; retain both appearance evidence and location belief. Do not import indoor object priors when the query is a whole landscape patch.
- **Evidence location:** task definition, distinctions from ObjectNav, benchmark construction, observations/actions, and evaluation protocol in the arXiv HTML, Sections 2–3. Source tier T1 (primary preprint). Dataset implementation is associated with [Habitat-Lab](https://github.com/facebookresearch/habitat-lab); this does not mean the baseline agent is open-source.

### N02 — Navigating to Objects Specified by Images

- **Authors/venue:** Jacob Krantz, Theophile Gervet, Karmesh Yadav, Austin Wang, Chris Paxton, Roozbeh Mottaghi, Dhruv Batra, Jitendra Malik, Stefan Lee, Devendra Singh Chaplot. ICCV 2023, pp. 10916–10925. [ICCV paper](https://openaccess.thecvf.com/content/ICCV2023/html/Krantz_Navigating_to_Objects_Specified_by_Images_ICCV_2023_paper.html), [arXiv](https://arxiv.org/abs/2304.01192), [project page](https://jacobkrantz.github.io/modular_iin/).
- **Task/data/observation:** HM3D InstanceImageNav: a random start in an unknown indoor scene, query RGB image of a specific object instance, current RGB-D and relative pose. Its discrete movement includes forward/turn/stop.
- **Architecture/training/memory/planning:** Four modules: frontier exploration, feature-based instance re-identification, projecting matched features into a map to localize the target, then analytical local path planning. Off-the-shelf models; zero task-specific fine-tuning. Memory is geometric/visual mapping, rather than just a recurrent policy state.
- **Results/code:** 56% success on the reported benchmark versus 25% for the strongest compared baseline; the paper also reports 88% success across a home and an office in real-world mobile-robot deployment. The paper describes the approach as off-the-shelf and zero-fine-tuning. A dedicated official GitHub implementation was not confirmed in the checked primary record; treat the paper/project/video as available and code availability as unverified.
- **Transfer:** The key transferable pattern is “query matching → candidate location estimate → deterministic route,” with frontier exploration while match evidence is absent. In the grid, a target descriptor/keypoint/correlation score can update a cell-level belief; shortest-path execution can remain exact. This is closer than category ObjectNav but still uses indoor objects and RGB-D geometry.
- **Evidence location:** official ICCV abstract and PDF, task/observation details and Figure 2 modular pipeline. Source tier T1.

### N03 — Instance-aware Exploration-Verification-Exploitation for Instance ImageGoal Navigation (IEVE)

- **Authors/venue:** Xiaohan Lei, Min Wang, Wengang Zhou, Li Li, Houqiang Li. CVPR 2024, pp. 16329–16339. [CVPR paper](https://openaccess.thecvf.com/content/CVPR2024/html/Lei_Instance-aware_Exploration-Verification-Exploitation_for_Instance_ImageGoal_Navigation_CVPR_2024_paper.html), [official GitHub](https://github.com/XiaohanLei/IEVE), [project page](https://xiaohanlei.github.io/projects/IEVE/).
- **Task/data/observation:** InstanceImageNav on HM3D-SEM. Goal RGB image and current egocentric observation; matching must tolerate viewpoint change and reject same-category distractors. The official repository notes velocity control and Habitat dependencies.
- **Architecture/training/memory/planning:** Explicitly switches among exploration, verification and exploitation. Verification treats “is this a target?” as a sequential decision, using image matching together with distance to the candidate. It tracks confirmed, potential and no-target cases. This goes beyond one binary target-confirmation output, but it remains an indoor instance-recognition system and requires learned components/pretrained detection/segmentation and matching models.
- **Results/code:** CVPR reports success 0.684 with a classical segmentation model and 0.702 with a robust model, compared with 0.561 for the cited prior method. The code is publicly available; its README provides executable Habitat evaluation setup and pretrained-model instructions.
- **Transfer:** Transfer the evidence accumulation/state machine, not the same close-range “approach to confirm” behavior: maintain a candidate-cell posterior and let diverse views / repeated patch evidence accumulate, while allowing a candidate to be rejected. Since target confirmation has already shown little gain in this project, compare this richer belief update against a direct visual-match baseline before treating it as a contribution.
- **Evidence location:** CVPR abstract/PDF; GitHub README lines describing sequential decision, distance-aware matching, candidate states, code and dependencies. Source tier T1.

### N04 — Topological Semantic Graph Memory for Image-Goal Navigation (TSGM)

- **Authors/venue:** Nuri Kim, Obin Kwon, Hwiyeon Yoo, Yunho Choi, Jeongho Park, Songhwai Oh. Presented at CoRL 2022 (oral; proceedings appear in PMLR volume 205). [PMLR paper](https://proceedings.mlr.press/v205/kim23a.html), [project page](https://bareblackfoot.github.io/TopologicalSemanticGraphMemory/), [GitHub](https://github.com/rllab-snu/TopologicalSemanticGraphMemory).
- **Task/data/observation:** Image-goal navigation in Gibson/Habitat, using panoramic RGB-D observations and an image query. The paper’s graph memory does not depend on a globally known robot position.
- **Architecture/training/memory/planning:** Incrementally builds a heterogeneous topological-semantic memory with image/view nodes and object nodes, then propagates context across them with a cross-graph mixer. A memory decoder retrieves context for current and goal nodes; an action policy chooses navigation action. The repository includes imitation-learning data generation and PPO/RL training: this is not a training-free drop-in.
- **Results/code:** The paper reports +5–9 percentage points in success and +7–23.5 points in SPL over its comparison baselines, and a mobile-robot demonstration. MIT-licensed public implementation and training code are available.
- **Transfer:** Replace a boolean visited set with a compact graph whose cell/view nodes hold image descriptors and target-match evidence; edges hold legal transitions or observed connectivity. A lightweight query-to-node attention/retrieval scorer is a possible small learned scorer, while graph construction and shortest-path planning can be deterministic. Keep the learned original as evidence, not as a required first implementation.
- **Evidence location:** PMLR abstract; project page’s memory-decoder explanation; GitHub setup exposes IL/PPO requirements. Source tier T1.

### N05 — UniGoal: Towards Universal Zero-shot Goal-oriented Navigation

- **Authors/venue:** Hang Yin, Xiuwei Xu, Linqing Zhao, Ziwei Wang, Jie Zhou, Jiwen Lu. CVPR 2025, pp. 19057–19066. [CVPR paper](https://openaccess.thecvf.com/content/CVPR2025/html/Yin_UniGoal_Towards_Universal_Zero-shot_Goal-oriented_Navigation_CVPR_2025_paper.html), [arXiv](https://arxiv.org/abs/2503.10630), [project](https://bagh2178.github.io/).
- **Task/data/observation:** One zero-shot framework for object category, image-instance and text-description goals, evaluated on multiple Matterport/HM3D/RoboTHOR benchmarks. Online observations are converted into an evolving scene graph; the goal is represented as a comparable graph.
- **Architecture/training/memory/planning:** Explicit scene/goal graph matching drives staged long-term goal selection. With no graph match it searches a goal subgraph; with partial match it uses coordinate projection and anchor-pair alignment; full match triggers scene-graph correction and verification. A blacklist helps switch away from failed hypotheses. It is a zero-shot LLM reasoning pipeline rather than a trained navigation policy; perception/graph construction still uses models.
- **Results/code:** The authors report leading zero-shot results across three goal types. No official source code link was present on the checked CVPR/arXiv pages, so code availability is recorded as unverified.
- **Transfer:** This is a strong reference for target-conditioned, multi-stage belief: “no match → seek query-related evidence; partial match → localize; full match → exploit.” For aerial grids, create a small goal representation from the query image and retrieve/match observations/regions; keep semantic relations as auxiliary evidence. Avoid 3-D object/room scene graphs if the grid already gives direct cell adjacency.
- **Evidence location:** CVPR full paper, abstract and graph-matching method; arXiv confirms accepted CVPR 2025 date. Source tier T1.

> N05 final-wave correction (2026-09-30): Gap-fill and independent verification confirmed [bagh2178/UniGoal](https://github.com/bagh2178/UniGoal) is a public official implementation with instance-image-goal support. The preceding unverified-code line records the first wave, not the final availability state.

### N06 — IGL-Nav: Incremental 3D Gaussian Localization for Image-goal Navigation

- **Authors/venue:** Wenxuan Guo, Xiuwei Xu, Hang Yin, Ziwei Wang, Jianjiang Feng, Jie Zhou, Jiwen Lu. ICCV 2025, pp. 6808–6817. [ICCV paper](https://openaccess.thecvf.com/content/ICCV2025/html/Guo_IGL-Nav_Incremental_3D_Gaussian_Localization_for_Image-goal_Navigation_ICCV_2025_paper.html), [project](https://gwxuan.github.io/IGL-Nav/), [GitHub repository](https://github.com/GWxuan/IGL-Nav), [arXiv](https://arxiv.org/abs/2508.00823).
- **Task/data/observation:** Habitat image-goal navigation on Gibson, including a free-view variant where query image camera pose/intrinsics differ; real robot test with a cellphone-captured goal. RGB-D observations and camera geometry are central.
- **Architecture/training/memory/planning:** Incrementally predicts a renderable 3D Gaussian scene representation. Coarse target localization performs discrete 5-D matching (target embedding as convolution kernel); once close, differentiable rendering refines target pose. Frontier exploration and Fast Marching Method route to the selected location. It uses learned feed-forward reconstruction/perception, but not a large policy trained for the target task; the paper has both zero-shot and supervised free-view evaluations.
- **Results/code:** Reported ImageNav success/SPL for Gibson includes 76.8/64.1 on the overall-straight setting; it reports gains across configurations and free-view zero-shot/supervised evaluations. Important release caveat: the official GitHub README says “Code is coming soon”; a public repository currently exposes a small landing page/assets, not a confirmed reproducible implementation.
- **Transfer:** The transferable insight is coarse visual localization followed by fine matching once evidence is strong. The full 3DGS pipeline is far beyond this grid project’s current state and compute budget; a multi-resolution patch descriptor or candidate-cell correlation map is a much lighter analogue.
- **Evidence location:** ICCV paper page, author project and repository README; dataset/method/evaluation details in paper Sections 3–4. Source tier T1.

### N07 — SemNav: A Model-Based Planner for Zero-Shot Object Goal Navigation Using Vision-Foundation Models

- **Authors/status:** Arnab Debnath, Gregory J. Stein, Jana Kosecka. arXiv preprint, submitted 2025-06-04; no peer-reviewed venue confirmed in the checked record. [arXiv](https://arxiv.org/abs/2506.03516), [arXiv full text](https://arxiv.org/html/2506.03516), [paper PDF on OpenReview](https://openreview.net/pdf?id=EZlJLnyI8L).
- **Task/data/observation:** Zero-shot category ObjectNav on HM3D in Habitat; RGB/depth and occupancy-map frontiers. This is semantic goal navigation, not exact aerial-image localization.
- **Architecture/training/memory/planning:** VLM/VFM performs target-aware semantic reasoning and assigns utility to candidate frontiers. A Long-term Search Planner (LSP) chooses a route/subgoal across frontiers. The complete method uses a pretrained local point-goal policy that was trained on the HM3D training split; its zero-shot claim concerns adding no task-specific ObjectNav policy training, not a wholly untrained navigation stack. Its greedy-vs-LSP ablation uses the same frontier scoring and shows a small efficiency gain for LSP.
- **Results/code:** Table 1 reports SemNav-Greedy at 34.3 SPL / 54.6 SR and SemNav with LSP at 35.9 SPL / 54.9 SR: +1.6 and +0.3 percentage points, respectively. Relative to VLFM (30.4 SPL / 52.5 SR), SemNav is +5.5 SPL points / +2.4 SR points, but that comparison also changes frontier-scoring prompts/model and does not isolate planning. These are author-reported HM3D results. Official code link was not confirmed in checked primary source.
- **Transfer:** Add a small budgeted search layer above the region proposals: rank top candidates, consider path cost and downstream options, then execute a persistent waypoint. Replacing the SemNav pretrained local point-goal policy with grid BFS is our proposed adaptation, not a component of SemNav. Replace the semantic object-location utility with query-image match likelihood and expected uncertainty reduction.
- **Evidence location:** primary preprint abstract, method/conclusion and HM3D comparison table; OpenReview PDF. Source tier T1 preprint.

### N08 — See, Point, Fly: A Learning-Free VLM Framework for Universal Unmanned Aerial Navigation (SPF)

- **Authors/venue:** Chih Yao Hu, Yang-Sen Lin, Yuna Lee, Chih-Hai Su, Jie-Ying Lee, Shr-Ruei Tsai, Chin-Yang Lin, Kuan-Wen Chen, Tsung-Wei Ke, Yu-Lun Liu. CoRL 2025, PMLR 305:4697–4708. [PMLR paper](https://proceedings.mlr.press/v305/hu25e.html), [arXiv full text](https://arxiv.org/html/2509.22653), [project](https://spf-web.pages.dev/), [official code](https://github.com/Hu-chih-yao/see-point-fly).
- **Task/data/observation:** Free-form instruction-conditioned UAV navigation/search, including DRL simulator tasks and real DJI Tello trials; egocentric RGB plus instruction; closed-loop re-observation. No query-image geolocation benchmark.
- **Architecture/training/memory/planning:** A frozen VLM outputs image-plane waypoint pixels and a discrete intended travel distance; camera geometry converts them to 3-D displacement; an adaptive distance controller and reactive low-level loop execute. No policy training or depth sensor required. Memory is short-horizon closed-loop perception, not persistent map memory.
- **Results/direct-vs-candidate evidence:** CoRL paper reports 93.9% sim and 92.7% real-world overall success on its task suite. Its same-paper navigation ablation compares direct text actions, PIVOT candidate-point selection, and SPF waypoint labeling with Gemini 2.0 Flash: authors report 7%, 40%, and 100%, respectively; Flash-Lite waypoint labeling reaches 87%. This is the clearest same-study evidence found for waypoint grounding outperforming text action generation, but it is not a four-cardinal-action grid or image-goal localization protocol.
- **Transfer:** If using a VLM for movement, have it select a map coordinate/cell or persistent subgoal from a displayed candidate map, then let deterministic BFS/A* execute. This reduces invalid free-form movement output. Adapt the paper’s distance scaling into a variable option duration, not 3-D flight dynamics.
- **Evidence location:** PMLR article, arXiv Sections 3–4 and Table 2, official project/repository. Public code is confirmed; it requires VLM API access. Source tier T1.

> N08 matched-backbone verification: Table 2 with Gemini 2.0 Flash is 7% / 40% / 100% for plain text / PIVOT / SPF. The 87% SPF value belongs to Flash-Lite and is not part of a same-backbone triplet. See independent verification file 08.

### N09 — Flying to Image-Specified Objects: 3D Quadrotor Navigation via Cross-Graph Memory and Viewpoint Planning

- **Authors/status:** Junjie Gao, Yuqi Chen, Yongzhou Pan, Yaosheng Deng, Jiaping Xiao, Mir Feroskhan. arXiv preprint, submitted 2026-06-29; no peer-reviewed venue identified as of the retrieval cutoff. [arXiv](https://arxiv.org/abs/2606.29917), [HTML full text](https://arxiv.org/html/2606.29917v1). No official code/project link was present in the checked arXiv record.
- **Task/data/observation:** Quadrotor InstanceImageNav in MP3D/VisFly, continuous 3-D environment, limited-FOV RGB-D and pose, exact object-instance image target. Success requires proximity plus visible target.
- **Architecture/training/memory/planning:** Hybrid object/observation memory graph plus 3-D occupancy grid. It generates candidate action/viewpoint nodes around frontiers and likely objects; candidates are scored with information gain, yaw diversity, path cost or target visibility, then linked to memory nodes. A graph encoder and pointer decoder trained with PPO select a candidate node; Hybrid A* plus B-spline optimization executes a feasible trajectory. This is not a training-free VLM planner.
- **Results:** On the paper’s MP3D/VisFly test setup it reports SR/SPL/CFR at Easy/Medium/Hard; full system reports SR .88/.69/.55 and SPL .58/.43/.31. Its ablations show drops when removing object-observation fusion, shortcut nodes, viewpoint generation or trajectory planning. These are preprint-reported results; replication and peer review are pending.
- **Transfer:** The most relevant UAV-specific structure is candidate viewpoint/waypoint generation, semantic evidence propagated through observation memory, and a separate executor. Use the structure at 5×5 scale with candidate grid cells and target-match scores; do not transplant 3-D PPO/trajectory optimization without need.
- **Evidence location:** full arXiv HTML Sections III–VI, especially IV–VI; exact publication status in arXiv submission history. Source tier T1 primary preprint, lower maturity than accepted papers.

### N10 — Embodied Navigation Foundation Model (NavFoM)

- **Authors/venue:** Jiazhao Zhang, Anqi Li, Yunpeng Qi, Minghan Li, Jiahang Liu, Shaoan Wang, Haoran Liu, Gengze Zhou, Yuze Wu, Xingxing Li, Yuxin Fan, Wenjun Li, Zhibo Chen, Fei Gao, Qi Wu, Zhizheng Zhang, He Wang. ICLR 2026. [ICLR paper page](https://proceedings.iclr.cc/paper_files/paper/2026/hash/ceb45c48e29e7f49b0b47edb98e43691-Abstract-Conference.html), [project page](https://pku-epic.github.io/NavFoM-Web/), [OpenReview/PDF](https://openreview.net/pdf?id=kkBOIsrCXh), [arXiv](https://arxiv.org/abs/2509.12129).
- **Task/data/observation/action:** Cross-task/cross-embodiment navigation foundation model trained on eight million samples spanning quadrupeds, drones, wheeled robots and vehicles, including VLN, object search, tracking and driving. Supports variable camera configurations and temporal horizons; predicts trajectory/action outputs that are post-processed by local planners.
- **Architecture/training/memory/planning:** Unified transformer with embodiment/camera and temporal tokens plus budget-aware sampling over visual history. This is heavy supervised/pretraining, not a small adapter-free trick. Project page shows server-side inference and per-robot local planners.
- **Results/code:** ICLR 2026 peer-reviewed; authors report leading/competitive results on seven benchmarks and real-world tests. Project page and paper are available; a public training/code repository was not verified in the checked official pages.
- **Transfer:** Treat as evidence that action interfaces may emit trajectories and that history can be budgeted, not as a feasible implementation baseline for RTX 4060 Laptop 8 GB. For this project, a compact learned scorer trained on existing grid episodes is the plausible light-training analogue.
- **Evidence location:** ICLR 2026 abstract, official project page, OpenReview paper. Source tier T1.

## Additional primary evidence cards (short)

### N11 — End-to-End Navigation with Vision-Language Models: Transforming Spatial Reasoning into Question-Answering (VLMnav)

Dylan Goetting, Himanshu Gaurav Singh, Antonio Loquercio; Neuro-Symbolic Systems / PMLR 2025. [PMLR](https://proceedings.mlr.press/v288/goetting25a.html), [paper/project](https://jirl-upenn.github.io/VLMnav/), [code](https://github.com/Jirl-upenn/VLMnav). It gives a VLM the goal plus RGB-D/pose and a map-derived, obstacle-aware candidate-action set; candidates are projected onto the image and the VLM selects one. It evaluates ObjectNav and GOAT-Bench with SR/SPL and reports its own prompting baselines, while noting it remains below stronger navigation specialists. Useful counterexample to the overstatement “direct VLM action = unconstrained raw motor output”: the action proposal/navigation filter makes direct selection grounded. This is not an image-grid head-to-head with waypoint policies. Source tier T1.

### N12 — GOAT-Bench: A Benchmark for Multi-Modal Lifelong Navigation

Mukul Khanna, Ram Ramrakhya, Gunjan Chhablani, Sriram Yenamandra, Theophile Gervet, Matthew Chang, Zsolt Kira, Devendra Singh Chaplot, Dhruv Batra, Roozbeh Mottaghi; CVPR 2024. [CVPR paper](https://openaccess.thecvf.com/content/CVPR2024/html/Khanna_GOAT-Bench_A_Benchmark_for_Multi-Modal_Lifelong_Navigation_CVPR_2024_paper.html), [GitHub](https://github.com/Ram81/goat-bench). Benchmark covers category, language and instance-image goals, sequential goals and lifelong accumulation; explicitly compares monolithic RL and modular methods and memory conditions. Useful for separating exact image goals from category goals and for measuring whether persistent memory improves repeated tasks. It is a benchmark, not a new waypoint/memory algorithm. Source tier T1.

### N13 — VLFM: Vision-Language Frontier Maps for Zero-Shot Semantic Navigation

Naoki Yokoyama, Sehoon Ha, Dhruv Batra, Jiuguang Wang, Bernadette Bucher; ICRA 2024. [IEEE record](https://doi.org/10.1109/ICRA57147.2024.10610712), [arXiv](https://arxiv.org/abs/2312.03275), [official code](https://github.com/rai-opensource/vlfm). RGB-D occupancy/frontier map plus pretrained VLM-derived semantic value map; a pretrained PointNav policy, trained on the HM3D train split with 2.5 billion steps across 4 GPUs (about 7 days, per paper), navigates to the chosen frontier/target. The high-level semantic selection is zero-shot, while the full navigation system relies on this learned low-level policy. Evaluated on Gibson, HM3D and MP3D, with real Spot demonstration and SPL. Transfer the planner value-map interface, replacing category/CLIP value with target-image cell belief. Do not count this as evidence for instance-level patch matching. Source tier T1.

### N14 — SG-Nav: Online 3D Scene Graph Prompting for LLM-based Zero-shot Object Navigation

Hang Yin, Xiuwei Xu, Zhenyu Wu, Jie Zhou, Jiwen Lu; NeurIPS 2024. [NeurIPS paper PDF](https://proceedings.neurips.cc/paper_files/paper/2024/file/098491b37deebbe6c007e69815729e09-Paper-Conference.pdf), [arXiv](https://arxiv.org/abs/2410.08189). RGB-D scene becomes a hierarchical object/group/room graph; LLM reasons over subgraphs and assigns scores to frontiers; FMM/local deterministic policy converts chosen frontier to actions. Zero-shot on MP3D/HM3D/RoboTHOR; graph relations and accumulated credibility address category-object false positives. This is stronger than a flat list of nearby objects but its hierarchy encodes indoor semantic relations, not map tiles. Source tier T1.

### N15 — OpenFMNav: Towards Open-Set Zero-Shot Object Navigation via Vision-Language Foundation Models

Yuxuan Kuang, Hai Lin, Meng Jiang; Findings of NAACL 2024, pp. 338–351. [ACL Anthology paper](https://aclanthology.org/2024.findings-naacl.24/), [arXiv](https://arxiv.org/abs/2402.10670), [official code](https://github.com/yxKryptonite/OpenFMNav). LLM expands free-form requests to candidate objects; VLM/Grounded-SAM discovers candidate objects and creates a Versatile Semantic Score Map; navigation uses map-guided language exploration/exploitation. Uses HM3D ObjectNav and reports zero-shot/real-robot evidence; open source confirmed. Relevant only if the query image is semantically decomposable into object/landmark relations; it is not exact aerial patch retrieval. Source tier T1.

### N16 — Dream to Recall: Imagination-Guided Experience Retrieval for Memory-Persistent VLN (Memoir)

Yunzhe Xu, Yiyuan Pan, Zhe Liu; arXiv 2025, published in IEEE TPAMI 2026, vol. 48(8), pp. 9035–9049. [IEEE DOI record](https://doi.org/10.1109/TPAMI.2026.3679426), [arXiv](https://arxiv.org/abs/2510.08553), [code](https://github.com/xyz9911/Memoir). A language-conditioned world model creates imagined future-view queries to retrieve both observations and behavioral history from hybrid viewpoint-level memory; used for memory-persistent VLN, not single-episode image search. Reports +5.4 SPL on IR2R vs its best memory-persistent baseline plus lower training/inference memory in its own benchmarks. Transfer only the retrieval pattern: query memory by predicted next-option/visual landmark and recall both past evidence and what action worked; don’t implement a world model for this small state space. Source tier T1.

### N17 — Human-like memory empowers embodied robots for long-term object navigation (HM-Nav)

Ying Zhang, Renjie Song, Hongliang Ren, Haibao Yan, Jin Liu, Changchun Hua, Cui-Hua Zhang et al.; Communications Engineering, published 2026-09-02. [Nature publisher article](https://www.nature.com/articles/s44172-026-00767-5). Peer-reviewed publisher-hosted early version. Combines multi-view fusion, adaptive dynamic semantic-spatial knowledge graph and experience-driven trajectory optimization from failures to suppress cycles in long-term ObjectNav. Abstract reports simulation and real-world evaluation but no exact metrics in the accessible abstract; code/dataset link was not verified. ### N18 — PONI: Potential Functions for ObjectGoal Navigation with Interaction-free Learning

Santhosh Kumar Ramakrishnan, Devendra Singh Chaplot, Ziad Al-Halah, Jitendra Malik, Kristen Grauman; CVPR 2022. [CVPR/project page](https://vision.cs.utexas.edu/projects/poni/), [arXiv](https://arxiv.org/abs/2201.10029). Learns target-conditioned potential values over frontiers from passive top-down semantic maps, then separates “where to search” from “how to navigate there.” It avoids RL interactions and reports strong ObjectNav with much lower training compute. Distinct from a generic region ranker because the potential is trained spatial value over map locations, but it is class/scene-prior driven; adapt only if enough target-image episodes exist to learn a small per-cell or frontier value scorer. Public code/checkpoints confirmed. Source tier T1.

### N19 — Learning to Explore using Active Neural SLAM

Devendra Singh Chaplot, Dhiraj Gandhi, Saurabh Gupta, Abhinav Gupta, Ruslan Salakhutdinov; ICLR 2020. [ICLR/OpenReview project page](https://www.cs.cmu.edu/afs/cs/user/dchaplot/www/projects/neural-slam.html), [arXiv](https://arxiv.org/abs/2004.05155), official code linked there. Modular hierarchy: learned map/pose module → learned global policy → analytical path planner → local policy. Primarily PointGoal/exploration, not target-image localization. Transfer the global long-term subgoal plus local route separation; do not train all modules for a 5×5 grid. Source tier T1, foundational.

### N20 — Object Goal Navigation using Goal-Oriented Semantic Exploration (SemExp)

Devendra Singh Chaplot, Dhiraj Gandhi, Abhinav Gupta, Ruslan Salakhutdinov; NeurIPS 2020, Advances in Neural Information Processing Systems 33. [NeurIPS paper](https://papers.nips.cc/paper/2020/hash/2c75cf2681788adaca63aa95ae028b22-Abstract.html), [paper PDF](https://proceedings.neurips.cc/paper_files/paper/2020/file/2c75cf2681788adaca63aa95ae028b22-Paper.pdf), [arXiv](https://arxiv.org/abs/2007.00643), [code](https://github.com/devendrachaplot/Object-Goal-Navigation).

The paper builds a top-down semantic map from first-person RGB-D and pose, then learns a target-conditioned global exploration policy using scene/object priors; a local planner executes the selected long-term goal. It won the CVPR 2020 Habitat ObjectNav challenge and reports mobile-robot transfer. This is category-level navigation and uses learned semantic/global components. Transfer the persistent belief-plus-global-subgoal structure, but do not use indoor room/object co-occurrence as the primary cue for an exact aerial image patch. Source tier T1.

### N21 — Frontier-Enhanced Topological Memory with Improved Exploration Awareness for Embodied Visual Navigation (FTM)

Xinru Cui, Qiming Liu, Zhe Liu, Hesheng Wang; ECCV 2024. [ECCV paper PDF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/08905.pdf), [paper/code page](https://mlanthology.org/eccv/2024/cui2024eccv-frontierenhanced/), [GitHub](https://github.com/IRMVLab/FTM-nav). Adds ghost nodes for unexplored but visible frontiers to a topological memory, predicts their perceptual features from historical observations, and uses multi-stage memory extraction to produce image-goal actions. Evaluated on Gibson image-goal navigation; online implicit feature prediction and end-to-end action generation require learned components. The transferable point is that memory can represent candidate next observations before visiting them; on a known 5×5 grid, candidate cells/frontier states are explicit and can feed persistent options and a search budget without training an implicit feature model. Source tier T1.

## Cross-paper answers to the architecture questions

### VLM direct directions versus waypoint/candidate scoring

Three concrete patterns are evidenced:

1. **Direct action choice over constrained candidates:** VLMnav selects from depth/occupancy-informed actions projected into the current image. This means the VLM chooses an action, but a conventional proposer first removes unsafe or unhelpful actions. It is a useful test baseline and supports keeping candidate generation separate from language/visual reasoning. [N11]
2. **VLM scores destinations, separate low-level policy acts:** VLFM uses a pretrained PointNav policy; SemNav uses a pretrained point-goal policy trained on HM3D; SG-Nav uses a local Fast Marching Method controller. For this grid project, BFS/A* is a simpler deterministic replacement proposed here, not what every source uses. [N07, N13–N14]
3. **VLM grounds a waypoint, geometry/controller executes:** SPF maps image-space pixel output plus a distance label into 3-D controls. Its own matched-task ablation gives direct-text action versus candidate waypoint selection versus 2-D waypoint labeling comparisons; this supports structured spatial outputs for its aerial tasks. It does not prove superiority over four-direction grid control in image-geolocation episodes. [N08]

Current evidence does **not** provide an apples-to-apples experiment with the project’s exact 5×5 observation/state/goal, equal model calls, same four action set, and identical budget comparing “VLM → cardinal action” to “VLM → persistent waypoint/option → deterministic planner.” Run that controlled ablation locally; do not cite the adjacent-task evidence as a theorem.

### What “more memory” should mean here

- The visited flag is coverage state, not a target belief. Add a per-cell evidence record: query-global embedding score, local correspondence score, count/quality/diversity of supporting views, last observation time and uncertainty. Keep class/landmark relation cues in a separate auxiliary field so a semantic guess cannot overwrite direct image evidence.
- A topological graph adds connectivity, revisitation cost and reusable edges; TSGM supports cross-node memory, while Frontier-enhanced Topological Memory (FTM, ECCV 2024) adds explicit “ghost frontier” nodes for visible but unvisited places. The current grid already gives adjacency, so a sparse graph may be most useful for persistent multi-step options, not duplicating geometry.
- Episodic retrieval should recall both *where similar visual evidence was observed* and *what route/option succeeded or failed there*. Memoir and HM-Nav motivate that second behavioral record; keeping it as a small table/hash retrieval avoids their much heavier learned world model/trajectory optimizer.

### Indoor versus aerial grid transfer limits

Indoor embodied navigation has continuous 3-D geometry, occlusion, ego-motion, turn angle, depth, room/object relations and stopping/visibility conditions. The project has known discrete 5×5 topology, current-patch observations, a query patch, and a short move budget; its difficulty is matching visual identity under patch/view changes and deciding which direction/region to sample. Thus transfer planner interfaces (belief, destination scoring, persistent option, path cost) and exact-image matching logic. Avoid assuming semantic object categories, RGB-D reconstruction, room graphs, continuous collision planning or a learned stopping policy are present or needed.

### Evaluation details to preserve

For every action-interface ablation, hold the VLM/backend, prompt context, number of API calls, total movement budget, training data and candidate observations fixed. Compare (a) four-direction ranking, (b) candidate cell/waypoint scoring, (c) multi-step persistent options with deterministic shortest paths, and (d) the same options plus target-evidence belief. Report success/target-cell accuracy, steps/path cost, revisits, visual-evidence gain, calibration/Brier or log loss for candidate-cell posterior, and API calls/tokens. Aggregate by map/target split, not only random episodes, to catch map memorization. These are recommended experimental controls, not claims measured in the papers above.
