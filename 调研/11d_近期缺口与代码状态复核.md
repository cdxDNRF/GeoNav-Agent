## 决策结论

截至 2026-10-01，没有找到一项已发表且任务协议足够接近的研究，能同时证明：同一视觉执行体上的多个决策角色，在相同模型、同一观测权限、相同总推理预算下，优于“单决策体 + 同样的结构化证据记忆”；并且用消息隐藏/打乱或角色删除证明收益由被消费的消息带来。当前证据是一正一反的边界组合：GUI 长程任务中 planner/actor/memory 分工明显胜过简单单模型基线，但推理调用、上下文与训练资源没有配平；火星车结构化决策任务中，完整结构化情境交给单模型已达到或超过多角色系统的点估计，且成本低得多。它们支持做严格的小型归因实验，不支持直接扩大开放式辩论或把“多Agent”本身当增益来源。[D01][D02]

就本项目而言，任务书所列 20 题小验证中，触发只落在 3 道原本成功题，唯一失败题没有触发；45 次导航请求均为 unknown/弃权，改变原动作 0 次。多数记录零触发；9 条有一轮调用，但没有第二轮实际消费交换消息。因此它没有形成“失败介入后被消息修复”的证据。原综述已覆盖图像导航、拓扑/视觉记忆与 AeroBelief；本文件不重写 DiscussNav、ReflectVLN、CA-VLN、Scaling Agent Systems、MAST，也不把通用多步推理等价成航拍搜索。等预算通用论文由主调研 B 单独核对，避免重复计为本缺口的直接导航证据。项目事实按任务书所列当前验收材料引用，未在本分工内重新运行模型或评测。[任务书](D:/桌面/XDUCS-courses/大四/大数据工程/调研/10_多Agent专项调研任务书_v1.md)；[原综述](D:/桌面/XDUCS-courses/大四/大数据工程/调研/DEEP_RESEARCH_active_image_goal_search.md)

## 对本项目可检验的缺口

接下来若要检验“多个决策Agent是否比一个Agent更能用好证据”，比较对象应冻结成下面三臂，而不是只与原策略比较：

| 臂 | 单位与状态 | 总预算约束 | 要识别的因果差异 |
|---|---|---|---|
| A 原策略 | 当前已冻结 Edge 导航策略和既有 cue 逻辑 | 模型调用为 0 或沿用现有协议，作为 SR/SG 基准 | 多出的调用最终有没有净导航价值 |
| B 单决策体 + grounded ledger | 一个同版本模型/决策体；对每条已观测证据维护结构化记录，并由同一决策体读取后给动作；ledger 只引用允许的当前/已访问观测 | 与 C 匹配每次介入的总调用、输入/输出 token 和图像输入；报告实耗，不只报告上限 | 结构化状态或更多推理本身能否解释提升 |
| C 隔离角色 + 消息消费 | 同模型的 planner 与 verifier，各自保留角色上下文；只能使用同样公开观测。verifier 独立判断后，planner 接收带证据 ID 的结构化消息，再给唯一动作提案 | 与 B 同总模型调用数、token 上限、观测图片、动作预算；若调用分配不同，另报固定总 token 敏感性结果 | 角色隔离和跨角色消息是否在单Agent ledger 以上增加有效信息 |

ledger 字段可固定为 `evidence_id, observation_id, observed_cell, target_or_hypothesis, supports/refutes/unknown, confidence, evidence_source, age`。字段值必须能回指实际已见 patch 或当前提示，不准写入未访问图像推断、真实目标距离或事后失败标签。C 的信息增益需能通过日志判断：消息是否到达、被解析、证据 ID 是否被最终提案引用、动作是否因此改变。消融至少包括“隐藏/打乱跨角色消息”和“移除 verifier”；若消息发出但不消费，结果与完整条件相同，就没有协作机制证据。

触发优先用公开状态的预算停滞/重复状态信号，另留无 cue 介入控制；当前 cue-conflict 规则只触发在成功样本这一项目事实提示它不能单独承担失败恢复测试。分别报告全体代表样本及预先定义的诊断子集，记录可介入机会数、非弃权覆盖、动作改变数、原成功被损伤、原失败恢复、SR、SG、Q、token/时延。先确认一条可归因机制（消息被读取并改变合理动作），再决定是否增加场景；不要把一致同意或角色数量当作机制证据。这里的介入条件和 ledger 方案是本次推论/实验建议，尚非论文已经在航拍网格上验证的结果。
