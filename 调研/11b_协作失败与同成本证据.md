# 11b｜协作失败与同成本证据

> 截止：2026-10-01。范围：同一导航执行体内的决策协作；不把多 UAV 并行当作同一问题。本文补充文献与方案，不改变项目结果。

## 决策摘要

现阶段不扩成常驻多 Agent，也不优先重复目标 cue 投票。可以保留一个受限的单因素试验：在公开轨迹状态显示反复走回头路、长时间无新覆盖或剩余动作预算已低时，调用一个独立“覆盖审查者”给出合法替代动作；以**相同结构化访问记忆、相同总调用/token 预算的 Edge 单 Agent**为主对照。独立角色若只重述同一观测、同一访问信息，不能算新信息；只有被证实的状态组织、独立假设生成或反证约束，才是协作假设。若触发不覆盖可修复停滞、触发后不改变动作，或不能胜过单体同记忆同成本，即停止这条支线。

当前本地事实（父级补充诊断，非文献）：S4 的 343 个失败中只有 11 个事后出现 pre-action 真邻接线索；SwissView 的 198 个失败中只有 1 个。它们是使用事后真值描述的机会数，不是可在线触发数，也不是可修复失败数的因果上界。上一批 20 题协作试验未改变原动作，且失败题未触发；6/6 像素身份诊断仅说明身份判别，不能说明方向判别。应测试预算覆盖/假设停滞，而非在稀少强 cue 上重复投票。

## 可测试角色流与淘汰条件

1. **覆盖/停滞监视者（首选）**：输入已访问格/边、动作历史、剩余步数和既有证据摘要；可因短窗重复状态、连续无新格/新证据或预算风险触发。独立给出 1 个合法替代动作及其预计新覆盖来源；不看未访问图像、真实距离或失败标签。若 trigger 不发生在有停滞的轨迹、提案不改变动作，或相较同记忆的单体 Edge 无净收益即淘汰。
2. **假设/证据账本员**：只归并已访问图像和逐步证据的出处、冲突、已否定假设，向探索器提供固定 schema。对照单体 Edge 获得同一账本模板和 token 预算；若 gains 仅来自额外上下文长度、账本丢信息，或隐藏账本消息后结果不变，则淘汰。
3. **盲独立路线审查者**：先独立读公开状态提一条路线建议，暂不看原规划；之后只看到结构化的 planner 动作/理由，标记重复路径或遗漏的合法覆盖。允许 veto/建议回退，默认原策略。必须统计错误共识、损伤成功、有效改变、弃权与时延；若多数跟随让正确动作变错，或独立阶段无法产出不同证据则淘汰。
4. **失败后反思 / cue verifier 暂缓**：只在观测冲突时审已访问证据，设计上可控，但失败样本可用 cue 机会极少；cue-only 试验不优先。若新抽样不能出现足够非 oracle 的在线触发，应直接终止。

总控制：固定相同观测、动作权限、动作预算、调用上限与总 token 预算；另报实耗 token/API/图片/延迟。统计所有代表性题的总体 SR/SG/Q，同时单列可触发停滞、触发率、有效动作改变、恢复失败、损伤原成功、弃权。角色删除、隐藏/打乱消息、强单体同记忆、单体两次反思作机制对照。触发条件仅依赖当前可见轨迹状态。

证据位置：B01 arXiv 摘要；B03 NeurIPS 摘要、Table 1 与 taxonomy/IAA 段；B05 ACL 摘要及同成本论述；B06 PMLR 摘要与 agreement-intensity 图表；B07/B08/B09 arXiv 摘要和结果段；B10 ACL 摘要与实验段；B11 arXiv 摘要与 debate setup。T1=同行评审论文或作者/机构正式代码数据；T1P=原论文预印本或未同行评审的原始研究。B07–B09 官方论文页未展示可核验代码链接，记为“未核验”，不据此断言没有代码。

## 独立核验后的限缩

最终报告按独立核验表处理：Scaling的180/4与260/6分别是v1/v3；MAST正式摘要使用“1600+”而不补未直接核到的1642，150专家样本不等于全量人工标签。B04 issue #13只保留为未验证的用户报告，不进入主结论。B08的matched thinking-token口径排除prompt及最终答案，且provider计量有偏差；B05/B06也不能笼统称所有实验严格配平实际总tokens。主实验只主张同调用安排/上限，并另报实耗；固定状态敏感性不冒充闭环等token效果。详见 `15_多Agent专项引用核验_v1.md`。

**主结论：** 多 Agent 的可信增益更可能来自可辨别的状态/证据差异、任务可并行性、模型差异或受约束的反证职责；多角色本身不等于新信息。当前基线已强、环境按动作串行、失败 cue 机会稀少，因此只允许一个受控的“公开状态停滞→替代覆盖计划”实验；若单体同记忆同成本追平，报告应收束而不是继续堆 Agent。
