# EVAL-001：MassGIS正式10×10/15×15协议冻结 v1

2026-10-04 / Codex / massgis-confirm-protocol-20261004。此批只准备协议、任务、引用清单与执行接口，不提取正式区域特征、不运行正式导航、不新增训练或网络调用。下一执行批次须在首次编码器forward前追加执行器/审计源码和缓存绑定，不能仅凭此文开始导航。

## 假设与作用域

冻结既有M0和Coverage3Radial，检验同产品新地区的目标证据与策略收益，并在相同物理任务上观察搜索面积从9km²扩大到20.25km²的影响。新产品迁移与扩区结果分别报告，不与旧MassachusettsRoads的68.04%直接相减。只有一个既定候选，不选种子、不换区域、不调模型、均值、0.50、覆盖三步/至少2格增益或公开起点径向保护。

仅DATA-006保留清单中事先固定的前10合格地区；3备用排除。任一区域绑定/质量失效均保存拒绝，不以导航成绩换区或减分母。2250原生600 RGB PNG只作路径引用，原件不移动或重复复制；0.5米/像素、300米/格、EPSG26986/north-up。10网格取原15网格行0..9、列5..14，15网格取全区，均B20。地理独立单位是10个完整区域，双网格/三权重/控制不增加地理样本数。源支持图幅可能相接，不能外推支持整图也有3公里间隔；预训练地理未知。

## 任务与配对

每区10网格75不同路线：短C4..8每距离5题；中C9..12与长C13..16分别7/6/6/6题。每距离层25题，前8题目标含原生源接缝、其余17题不含；每区以NumPy种子81007+事先区域序号按合法有序端点枚举后无放回抽取。

15网格保留这75条路线的完全相同物理端点，转换为15格ID，pair_id逐一对应；这750条共同任务专门比较面积扩大。每区另加25条远距C17..20（7/6/6/6）任务，前8题接缝、其余17题内部，使用同一随机流继续无放回采样。共10网格750、15网格1000不同路线；15格共同队列权重各层1/3，完整混合队列四层各1/4，目标接缝均32%。距离21..28不可在B20内完成，本协议明确排除，不事后调整分母。

错误目标排除起点与真实目标，优先同起始距离并取行优先第一个；若无候选，按距离差/ID最小并逐题记录例外。两个网格的错误目标集合各自冻结，不要求同一错误目标物理位置。真实目标、源、距离、pair_id和分层只用于评测，不能传给策略。

## 模型、输入与执行顺序

Sat2Cap冻结float32/原224 BICUBIC预处理；Small256 NoTarget探索器和EdgeTargetCue头三组权重0/1/2、全部拟合均值，边缘仍600→300 BOX桥接。所有权重/均值/编码器及原配置SHA均绑定；模型参数不扩大。

公开输入仅Observation/StepInfo、当前图及给定目标图两组特征。完整2250特征库属于评测器，不交给策略；每题清空GRU/profile缓存。四动作；越界原地耗步；首次到达成功、最后一步成功优先；无stop。正式环境另用显式confirm协议与test身份，不放宽旧dev环境或修改全局协议注册表。

顺序：合成接口/旧18项回归→预登记及源码快照→重放已保存开发450题/7217动作→独立几何/任务/错目标/来源/哈希审核→下一批冻结执行器与资源→2250原图特征和282480静态头预测→独立特征核验→首动作前封存→逐网格Full主对照→独立重放和主门槛判定→只有该网格主门槛通过才追加Baseline/CueMean/CueWrong→独立复核与最终判定。一个网格失败不自动阻止另一个网格按已冻结条件完成；全部成绩保留。

模型正常运行与任务成功是不同指标。部分JSONL、输入哈希漂移或不一致记录立即停止并保存拒绝；完整作业按输出封存核对后复用，不能覆盖重跑或重新随机采样。

## 门槛：每个网格分别判定

沿用上一独立策略确认的比较门槛，而非SR60%的通用绝对线。

| 判定 | 预定必要要求 |
|---|---|
| 工程正确 | 全计划作业正常终止；神经动作无越界、特征有限、绑定/重置无误；旧轨迹精确回归及另实现指标/状态/覆盖复核通过。旧规则越界保留且耗步，规则不代替模型验收 |
| Coverage相对同题M0 | 混合SR至少+2个百分点；至少2/3权重正差；全部终局SG不变差；各距离层SR损伤≤2点且SG不变差；按完整区域配对95%差下界>0。15网格完整混合及共同75题子队列都满足总体门槛，四个距离层分别保护 |
| 目标有效性 | Coverage Full对禁用、均值、错误目标各自SR至少+5点、至少2/3权重正、全部终局SG不变差、完整区域配对95%差下界>0 |
| Raw视觉头 | Full正确邻接接受召回≥50%、接受正确精度≥90%、至少30正确接受，Full召回相对均值≥10点；按五类top/0.50直接统计，不借合法/未访问门控修饰 |
| 实际误触发保护 | Coverage Full错误cue接受次数/全部实际执行动作≤5%，含接缝目标子队列同样≤5%；相对禁用目标，原成功被Full损伤的比例≤全部计划题的2%。分母明确、三权重合并，同时报告各权重/区域/距离层 |

完整区域bootstrap固定4000次、种子7317，每次抽取10个区域并保留同区所有路线/三权重，先在区内等权合并权重；差值先配对再抽样。不是按单题或种子抽取“独立样本”。两网格共用地理单位，不合并成20区；共同物理任务的面积对照另报告配对差，不另设一个未经论证的普适SR衰减阈值。更远C17..20只在15网格存在，不能混入跨网格配对差。

实际误触发门槛以行动预算损耗衡量；**不代表接受精度达到95%或90%**。实际正确接受/全部接受必须同时报告，即使误触发占所有动作比例较低也不能隐藏。DATA-007的10格实际接受精度67.40%、15格raw精度88.91%是已知风险，不能保证新网格可靠性门槛通过。≥90% raw要求适用于本批两个网格；任何失败均保留，不在看正式分数后降低要求。

相对禁用目标的“损伤”由同题结果配对定义，不证明每次误触发的因果。对均值/错误目标同样报告恢复/损伤。Raw与实际接受的接缝分层均报告；静态概率只用于评分，不参与重新挑阈值。

只有一个网格全部必要门槛与复核通过，才有该网格的新产品默认候选资格；默认登记仍另立任务，不自动改默认。若10网格通过而15失败，只能限定10网格，不借原S2/S3/S4声明15通过。
