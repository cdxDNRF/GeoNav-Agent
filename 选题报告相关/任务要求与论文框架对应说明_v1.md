# 正式任务要求与当前方法对应

2026-10-01。以本轮用户提供的课程要求为准，不改写历史实验结论。

要求：面向无人机等智能体在大范围未知区域中的视觉地理定位，基于GOMAA-Geo、GeoExplorer等框架，构建智能体与地理环境交互平台，根据连续航拍观测自主选择探索方向、逐步定位目标。

| 要求 | 当前实现与证据 | 尚需限定 |
|---|---|---|
| 环境交互平台 | `project/src/env/environment.py`的局部观察、四方向转移、预算、到达终止；`eval/`冻结任务、轨迹、评测、重放 | 离线航拍切图仿真，非无人机实飞 |
| 连续视觉与自主行动 | 冻结Sat2Cap当前图特征，GRU跨步状态、visited和剩余预算；训练视觉头判断目标邻接，阈值允许可信线索介入 | 当前默认为训练过的单智能体模块系统 |
| 给定目标搜索定位 | 目标航拍图与当前图配对，有限步数内到达目标网格；SR与全题终点SG | 输出网格位置，未输出真实经纬度，未验证地面图/文本目标 |
| 大范围未知区域 | 10×10网格/B20及SwissView新源文件同模态迁移已验证 | 10×10主要增加同范围切图密度；实际覆盖扩大、真实异时/任意方向/实飞仍未验证。未知指未访问图像与目标位置未知，网格坐标和动作转移公开 |

## 两篇论文实际借鉴范围

[GOMAA-Geo原论文](https://arxiv.org/abs/2406.01917)的完整方法包含跨模态表示对齐、序列基础模型监督预训练与强化学习。当前`data/process_masa.py`对照官方切图/特征脚本采用行优先5×5、Sat2Cap特征格式，交互任务借鉴有限预算的主动地理定位，策略使用监督/强化学习；资源限制下用小型GRU替代原大型历史序列模型。没有复现原完整模型、跨模态训练或其全部基准。下载的官方`GOMAA-Geo/`仓库只读参考，自己的平台位于`project/src/`。

[GeoExplorer原论文](https://arxiv.org/abs/2508.00152)以环境建模的好奇心内在奖励增强主动探索。`train/curiosity_controlled.py`明确标为改编，用独立动态预测模块、预测误差奖励及距离相关门控作同预算对照；未完整复现GeoExplorer。该因素没有稳定优于PBRS，当前最佳方案未启用好奇心。SwissView同模态迁移借鉴其数据与跨域评测方向，不能把借鉴数据称为启用了其策略。

训练小模型符合要求，也符合两篇参考方法包含训练的事实。GOMAA-Geo所说zero-shot是不同目标模态等泛化能力，并不代表没有训练。多Agent不是正式要求的前提；本次只在已验收系统上验证无需新增训练的协作层，不将整个系统称为零训练。
