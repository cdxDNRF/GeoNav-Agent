# DATA-002：真实15×15原生影像与任务工程冻结方案

2026-10-03，首次完整影像请求前登记。由Codex顺序执行；中断后按本批注册、请求账本和执行锁恢复。旧数据、默认、训练模型、历史批次和DATA-001全部只读。本批不训练、不调用策略/云端、不执行导航动作，不产生新SR。

## 输入、资源与恢复

1. 唯一新源是DATA-001的Roads113组三乘三候选涉及的263个源；固定文件名升序，保留官方集合、train/valid/test分区、原URL和已验证地理标签/64KiB前缀SHA。不加入Buildings或新目录，不按导航成绩增删源。
2. 下载最多263新源，每URL最多2次、正文单文件最多8MiB，总正文预算2.5GiB；两路并发、单请求45秒。首次获取前至少8GiB可用空间。正文计账不声称测量TCP/TLS开销。
3. 每次开始即消耗尝试并预留8MiB。每MiB保存进度；完成/失败以实际读入正文计费，中断未结算请求保守按8MiB计费。已知完成字节只读复用，不用删账本或重置次数扩大预算；失败片段保留在新目录。仅200完整响应，目录/标签/权重不在获取范围。
4. 本批采用操作系统独占执行锁，避免接手者重复启动相同获取/选择/构建进程；锁不是整个仓库的协作锁。先检查TASKS和HANDOFF，未知旧进程不擅自停止。
5. 新原数据：`DATA/raw_data/MasaRoads/真实十五乘十五数据准备_v1/{tiff,失败片段}/`；新派生：`DATA/processed_data/MasaRoads/真实十五乘十五数据准备_v1/`。目录先在README登记，原目录不迁移/覆盖。来源、源码及输入在首下载前绑定哈希。

## 完整质量与空间规则

- 完整原件须与已保存前缀SHA及GeoTIFF标签匹配：单RGB1500图、单帧、北向、1米像素、EPSG26986、米、PixelIsArea。地理容差1毫米。
- 精确全黑/全白像素：每1500源比例≤1%，每300×300图块比例≤2%。不改既有阈值，不引入模型分数或主观照片好坏筛选。低质量原件/判定保留，不重新下载追过线。
- 记录完整文件SHA及RGB像素SHA；拒绝与原151/已消费24相同像素的源，以及彼此像素相同的新地理源，全部重复源都拒绝。工程已知数据复用不算新确认源。
- 候选9源组成原生3×3，按真实坐标严格无缝，面积20.25km²。新确认区与原151、已消费24、工程区和彼此至少3公里完整边界间隔，不以中心点距离代替。
- 在质量通过的候选图上重算最大相容子集：固定候选顺序和确定性颜色界搜索，最多30秒；结果必须证明最大值，另用HiGHS冲突优化复核。容量≥10时对最大子集按9源文件名序列排序，取前10；不能按模型成绩或最漂亮地图选区。容量不足10时保留未过状态，不启动正式导航，不改数量/阈值。
- 工程优先复用原137训练源内的3×3提案：按文件名坐标次序，固定质量规则，取前两个源身份不重叠组。旧151原件先核对SHA，无新增工程影像下载；工程不作为独立泛化证据。

## 图像、任务与诊断

1. 每区4500×4500原生GeoTIFF，逐源拼接，不放大、不重采样、不混合；225个300×300图块，JPEG质量75与既有策略一致。记录逐格来源、原生/发布像素SHA、像素窗与投影边界。接缝1500/3000像素的亮度差只作诊断，不作为选型门槛。
2. 工程2区`img_5000—5001/dev`、确认10区`img_5100—5109/test`。上游分区保留在每源记录，与本项目角色区分。质量/工程不够时不伪造完整12区；可保留实际工程产物及未达标判定。
3. 每区75不重复路线：长距离C12—16各5题；接缝目标C8—12各5题；内部目标C8—12各5题。采样种子6503，完整75题跨分层不重复；B20、15×15、300米/格。接缝目标轮转覆盖第5和第10格边界、水平/垂直及两侧8组合，排除交叉接缝；内部目标不贴源边界。
4. 错误目标种子6511，始终同初始距离、异于真实目标和起点。每源内部边界的120个有向邻接对，各生成跨源邻接/同源邻接/非邻接3种探针，每区360条。探针不是导航成绩。
5. 用公开环境reset逐题核查图像/协议，不执行任何方向动作或加载神经策略。初始距离、目标位置、源身份、分层及探针标签只归评测器，不进入Agent。
