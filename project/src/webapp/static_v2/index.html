覆盖收益与径向保护
目标线索通过门控时优先；其余状态最多规划3步，覆盖机会收益至少增加2，且下一步到公开起点的径向距离不得小于原探索动作。
同题工程对照
原S2/S3/S4与9km²确认各自有效；MassGIS正式10/15格仍未通过新域门槛。当前Cloud对照不是算法多Agent。
